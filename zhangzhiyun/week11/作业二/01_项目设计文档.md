## 1. 项目背景

企业内部的传统 BI 体系存在两个长期矛盾：

1. **需求积压**：业务人员临时性、探索性的取数和分析需求，需要提需求 → 排期 → 开发 → 验收，周期以天/周计；
2. **使用门槛**：固定报表覆盖不了长尾问题，业务人员又不具备写 SQL 的能力，数据团队被迫成为"人肉取数机"。

大模型（ChatGPT / DeepSeek / Qwen / 豆包等）在自然语言理解和代码生成上的成熟，使"自然语言问数"（ChatBI / Data Agent）成为可能。

## 2. 项目定位

**一句话定位**：面向企业内部业务用户，提供"自然语言提问 → 可信数据答案（数字、图表、结论）"的自助式分析入口。

**与传统 BI 的关系（互补而非替代）**：

| 维度 | 传统 BI | ChatBI / Data Agent |
|---|---|---|
| 交互方式 | 拖拽、固定报表、看板 | 自然语言、多轮追问 |
| 交付链路 | 提需求→排期→开发→验收 | 即问即答，分钟级 |
| 覆盖场景 | 高频、稳定、规模化报表 | 长尾、临时、探索、下钻、归因 |
| 输出形态 | 图表、报表 | 图表 + 结论 + 可追溯 SQL/口径 |
| 核心风险 | 口径分散、需求积压 | 答错放大、越权、幻觉 |

**边界**：ChatBI 不替代财务对账、监管报送、高频固定报表等强确定性场景。

## 3. 项目目标

### 3.1 业务目标
- 临时取数需求的自助解决率 ≥ 70%（首次回答解决率）；
- 数据团队被动取数工作量下降 50% 以上；
- 核心业务域高频问题覆盖问数场景。

### 3.2 质量目标（参考基线）

| 指标 | 目标 |
|---|---|
| SQL 可执行率 | ≥ 98% |
| 单表简单问题结果准确率 | ≥ 90–95% |
| 多表/指标类问题结果准确率 | ≥ 75–85% |
| 核心指标口径一致率 | ≥ 95% |
| 低置信度澄清覆盖率 | ≥ 90% |
| P95 响应时延 | < 5–10s |

## 4. 核心价值主张

1. **降低门槛**：业务用户不需要知道表名、字段名、SQL；
2. **缩短链路**：临时问题从"周级排期"变成"分钟级自助"；
3. **覆盖长尾**：传统 BI 覆盖不到的大量临时/探索分析；
4. **支持多轮**：追问、下钻、对比、归因，而非一次性查数；
5. **输出结论**：给关键变化、异常、驱动因素和限制条件，不只是图表；
6. **沉淀语义资产**：问数反馈反哺指标口径、同义词、业务知识；
7. **治理前置**：权限、口径、审计在查询链路中统一控制。

## 5. 用户与场景

| 角色 | 典型场景 |
|---|---|
| 业务运营 | "上个月华东区销售额多少？环比呢？" "卖出最多的前 5 个商品是什么？" |
| 管理层 | "今年销售趋势怎么样？" "为什么 3 月跌了？"（归因型） |
| 数据分析师 | 复杂多表查询的快速草稿，或长尾问题兜底 |
| 数据/平台团队 | 语义层运营、指标 Owner、Badcase 治理 |

## 6. 成熟度路线图

| 阶段 | 特征 | 定位 |
|---|---|---|
| L1 问答取数 | 单表/简单聚合 NL2SQL + 图表展示 | 内部试点（MVP） |
| L2 语义层受控 | 指标/维度统一、多表 Join、权限下推、可追溯 | 生产可用起点 |
| L3 多轮分析 Agent | 任务规划、下钻、对比、归因、澄清 | 成熟 ChatBI |
| L4 主动洞察 | 异常监控、主动推送、行动建议 | 进阶 |

**本项目第一年目标：L2 稳定 + 局部 L3**，不追求"全自动自由 SQL"。

## 7. 关键成功要素（讨论共识）

1. **语义层优先**：生产主链路走 `NL → 语义查询 → SQL 编译`，LLM 不做全库自由写 SQL 的默认路径；
2. **准确性是生命线**：先建评测集和 Badcase 闭环，再扩场景；低置信度澄清优先于猜测；
3. **权限不是 Prompt 的事**：语义层 + 执行层双重校验，全链路审计；
4. **持续运营**：指标与知识必须有 Owner，建立反馈标注、灰度发布与回归评测机制。

## 8. 主要风险与对策

| 风险 | 对策 |
|---|---|
| 错答摧毁信任（错误往往"看起来很像对的"） | 置信度分级、理解回显、结果 Sanity Check、答案附 SQL 与口径溯源 |
| 口径打架（同名不同义） | 语义层统一指标口径，指标唯一 Owner |
| 越权与数据泄露 | 行列级权限编译期注入、只读账号、脱敏、全量审计 |
| 大查询拖垮生产库 | 查询网关：限流、超时、Dry Run、结果行数上限 |
| 项目"上线即巅峰" | 知识运营后台 + Badcase 周会闭环 + 回归门禁 |
