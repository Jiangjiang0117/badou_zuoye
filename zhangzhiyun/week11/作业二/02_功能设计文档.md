## 2. 核心功能详设

### F1 对话问数

**F1.1 自然语言问数**
- 用户输入自然语言问题，系统返回：**答案结论 + 图表 + 所用 SQL（可展开）+ 数据口径说明**。
- 响应分两级：先流式给出"我理解的问题"，再给结果（理解回显机制）。
- 理解回显格式：`指标=销售额（不含税）｜时间=2026-09 自然月｜维度=地区｜过滤=无`，支持一键修正——这是成本最低的准确率保险。

**F1.2 多轮追问与下钻**
- 支持指代消解与条件继承："那广东呢？"（继承上轮指标与时间）；
- 支持下钻："按月份拆开看看"、"只看 Top 3 客户"；
- 当前继承的条件显式展示，允许用户修改；
- 多步分析（对比、归因）拆成多次查询编排执行。

**F1.3 歧义澄清**
- **分级澄清策略**：只在歧义、低置信、高风险（如涉及薪酬）、权限敏感时追问；其余直接答。
- 澄清形态：选项化（"销售额"有 3 种口径，请选择）+ 文本追问。
- 原则：**澄清优先于猜测**；澄清覆盖率目标 ≥ 90%。

### F2 数据理解与语义资产

**F2.1 数据库自动解析**（作业一 DBParser 的产品化）
- 自动采集：表/字段/类型/注释/主外键/行数/枚举值/样例数据/空值率/更新时间；
- 解析结果进入元数据存储，并生成供 LLM 使用的"表画像"。

**F2.2 语义层**
- 定义核心指标（名称、口径、公式、时间口径、同义词、Owner）、维度、实体关系（Join 路径）、业务规则库（含税/退款/去重等）；
- NL 先转"指标 + 维度 + 过滤 + 粒度"的语义查询，再编译成 SQL；
- 指标必须唯一口径、唯一 Owner，版本化变更。

**F2.3 知识运营后台**
- 同义词/别名管理、枚举值字典、业务知识条目、常见问法模板的增删改查与版本管理；
- Badcase 标注工作台：标注 → 归因 → 补知识/样本 → 进评测集。

### F3 NL2SQL 引擎（核心链路）

按作业一实现的 workflow 产品化，七个环节全部保留：

| 环节 | 功能要求 |
|---|---|
| 数据库解析 | 见 F2.1，离线定时刷新 + 变更感知 |
| Table 选择 | 业务域路由 + 向量/关键词召回 TopK 表 + 精排；漏表是硬伤，召回率优先 |
| SQL 生成 | 结构化 Prompt：相关表画像 + 外键关系 + few-shot 检索（相似问答）+ 业务规则；输出强约束（只输出 SQL / 结构化 JSON） |
| SQL 校验 | ① 安全校验：仅允许 SELECT（正则 + AST 双保险）；② 静态校验：sqlglot AST 检查语法、表列存在性、聚合一致性、笛卡尔积；③ Dry Run：EXPLAIN 预编译与成本预估 |
| SQL 改写 | 校验/执行失败时携带报错信息回喂 LLM 自修复；**限 1–3 次、保留每轮 diff、防止把对的改错** |
| SQL 执行 | 只读连接 + 超时 + 结果行数上限；超限明确提示"已截断" |
| 结果汇总 | LLM 摘要**必须绑定查询结果**：数字逐个引用、结论先行、空结果说明原因；区分事实与推断，不做无依据归因 |

### F4 查询执行
- 统一执行网关：限流、超时、资源隔离、缓存（高频问题）、审计；
- 只读账号 + 最小权限；禁止直连生产主库。

### F5 可视化
- 图表推荐规则：趋势→线图；分类对比→柱状图；占比→饼图（≤6 类）；分布→直方图；相关→散点图；
- 图表必须标注口径、时间范围、过滤条件；
- 支持从图表继续追问（下钻、切换维度、导出）。

### F6 结果解释与洞察
- 自动摘要回答"是什么、变化多少、和谁比、哪里异常"；
- 贡献度/TopN 变化/异常点由**算法计算**（非 LLM 编故事），LLM 负责组织表达；
- MVP 阶段只做"事实陈述"，不做"原因推断"。

### F7 安全与权限
- SSO 登录；行级/列级/指标级权限在**语义层编译期注入 SQL**（Prompt 不是权限边界）；
- 敏感字段脱敏；导出管控；
- 全链路审计：谁、何时、问了什么、看了什么数据、生成了什么 SQL。

### F8 评测与反馈闭环
- 黄金评测集 300–1000 条：分业务域、分难度、含多轮/歧义/权限/时间边界题型，带"期望结果"；
- 每次改 Prompt/模型/语义层跑回归门禁 + 灰度发布；
- 用户赞/踩 + 归因标签；Badcase 周会闭环，闭环时长 ≤ 1 周。

## 3. 关键用户流程

```
用户提问
   │
   ▼
意图识别 ──非问数──▶ 闲聊/引导/转人工
   │ 问数
   ▼
歧义判断 ──低置信/高风险──▶ 澄清追问（选项化） ──┐
   │ 高置信                                     │
   ▼                                            │
理解回显（指标/时间/维度/过滤）◀──── 一键修正 ────┘
   │
   ▼
表召回 → SQL 生成 → 校验 ──失败──▶ 自修复(≤3轮) ──仍失败──▶ 兜底话术+转人工
   │ 通过
   ▼
权限注入 → 只读执行 → 结果 Sanity Check ──异常──▶ 标注"结果可能异常"
   │
   ▼
图表推荐 + 自然语言摘要 + SQL/口径溯源
   │
   ▼
用户反馈（赞/踩）──▶ Badcase 闭环
```

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | P95 响应 < 10s；缓存命中 < 2s |
| 可用性 | 核心服务 99.9%；LLM 故障自动降级（备用模型） |
| 安全 | 数据不出域策略；模型调用走受控网关；敏感数据脱敏后才可进外部模型 |
| 可扩展 | 新数据源接入 ≤ 1 人日（配置化连接器） |
