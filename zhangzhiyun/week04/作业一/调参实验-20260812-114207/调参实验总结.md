## 三、调整依据(为什么这么调)

第一轮(seed=42)实验揭示了两个关键现象:

1. **warmup_steps 是最大的杠杆**:训练总共只有 78 步,而 warmup=50 意味着学习率要爬 50 步才到顶,全程几乎都在'热身',没真正用满学习率。把它设成 0 后,准确率从 0.94 跳到 0.97,而且用时最短。
2. **学习率不能太小**:lr=2e-5 时 6 轮都收敛不完(最终 loss 1.92),准确率反而掉到 0.93。

因此本轮全部实验**先把 warmup=0 固定下来**(等于把已被证明有效的改进纳入基线),再逐项试探:学习率往温和/激进两个方向、批量减半、序列加长,最后组合这些方向冲高。

## 四、逐项解读(对照第一轮)

| 实验 | 本轮结果 | 解读 |
|---|---|---|
| exp1(lr=3e-5) | 0.96 | 学习率再温和一点,6 轮内学得反而略少,比 5e-5 的 0.97 差一点点。 |
| exp2(lr=1e-4) | 0.95 | 更大学习率并没有更快更好:步子太大,epoch 5、6 准确率反而从 0.96 回落。 |
| exp3(batch=16) | 0.93 | **与 warmup=0 叠加反而最差**:小批量 + 全程满学习率 = 更新噪声更大,不如批量 32 稳。 |
| exp4(max_len=128) | 0.97 | 与 max_len=64 完全持平,每轮训练曲线几乎一模一样:64 已够用,加长只是白花内存/时间。 |
| exp5(三样组合) | 0.95 | 把温和学习率+更多轮次+更小批量堆在一起,没有 1+1>1,反而互相抵消。 |

## 五、结论

1. **本轮没有突破 0.97**:最优仍是 warmup=0、lr=5e-5、batch=32、epochs=6、max_len=64(第一轮已找到,本轮再次验证);exp4(仅 max_len=128)与它持平。
2. **学习率的最优点就是 5e-5**:把两轮结果合起来看,2e-5→0.93、3e-5→0.96、**5e-5→0.97**、1e-4→0.95,5e-5 正是这个小数据集上的甜点。
3. **batch 与 warmup 会相互影响,不能孤立地调**:batch=16 配 warmup=50 能到 0.95,但配 warmup=0 反而掉到 0.93——批量越小越需要预热来稳住学习率。
4. **max_length 在这个任务上无关紧要**:意图文本很短,64 与 128 的训练曲线完全相同。
5. **真正的瓶颈是数据,不是超参数**:500 条数据、100 条测试,0.97 意味着 100 条里只错 3 条,已接近该数据量上限。想再提升,应该加数据 / 数据增强 / 换更大模型,而不是继续堆超参数。
6. 可复现:所有实验固定 seed=42,对比公平;每份日志首部就是可复跑的超参数。

## 五、结论

1. **本轮最优:exp4-预热0-加长128 → 准确率 0.97**(batch=32, epochs=6, warmup=0, lr=5e-05, max_len=128)。
2. 是否提升:见上方对比表;若仍为 0.97,说明 500 条小数据下准确率已接近上限,继续调参收益很小,下一步应加数据/数据增强,而不是再堆超参数。
3. 可复现:所有实验固定 seed=42,对比公平;加参数复跑命令见各日志首部。
