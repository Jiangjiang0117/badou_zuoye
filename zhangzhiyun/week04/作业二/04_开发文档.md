## 一、总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                       使用层 (3 个入口)                       │
│   demo.py (交互演示)  train_*.py (训练)  serve.py (HTTP API) │
└─────────────────────────────────────────────────────────────┘
                          │ 调用
┌─────────────────────────────────────────────────────────────┐
│                   服务层  intent/service.py                  │
│            IntentService: 统一入口 + 置信度路由               │
│        ┌───────────────┬──────────────┬──────────────┐      │
│   BERT 微调           LLM 兜底        基线对比          │      │
│ bert_classifier.py   llm_router.py  baselines.py    │      │
└─────────────────────────────────────────────────────────────┘
                          │ 复用
┌─────────────────────────────────────────────────────────────┐
│                   基础层  intent/config.py                   │
│                  data.py / metrics.py / server.py            │
└─────────────────────────────────────────────────────────────┘
```

**分层原则**:服务层只管"路由决策",模型层只管"算概率",基础层管"数据与工具"。各模块可独立替换(例如把 HTTP 服务换成 FastAPI,接口不变)。

## 三、核心模块接口定义

### 1. `intent/service.py` — 服务统一入口

```python
class IntentService:
    @classmethod
    def load(cls, saved_dir="bert_model", threshold=0.80, llm_router=None)
        # 从 outputs/bert_model 加载 BERT + 标签映射,构造服务

    def predict(self, text, use_llm_fallback=True) -> dict
        # 返回:
        #   {text, intent, score, source, used_llm}
        #   source ∈ {"bert", "llm", "mock"}
        #   used_llm: 是否走了置信度兜底

    def predict_batch(self, texts) -> (preds, scores, used_llm_flags)
        # 批量识别,供 evaluate.py 使用
```

**路由规则**(伪代码):
```
probs = bert.predict_proba([text])
if max(probs) >= threshold:  return intent=argmax(probs), source="bert"
else:
    llm_label = llm.predict(text)          # 已配置 API 时
    if llm_label: return intent=llm_label, source="llm"
    else:         return bert 的原始结果(兜底失败不抛异常)
```

### 2. `intent/bert_classifier.py` — BERT 微调

```python
class BertIntentClassifier:
    def train(self, splits, output_subdir="bert_model") -> {"output_dir", "history"}
    def predict_proba(self, texts) -> np.ndarray     # (N, num_labels) 概率
    def predict(self, texts) -> np.ndarray           # (N,) 预测下标
    @classmethod
    def load(cls, saved_dir="bert_model")
```

训练细节:
- 预训练权重:`models/google-bert/bert-base-chinese`(离线);
- 训练器:HuggingFace `Trainer`,评估指标 = accuracy + macro-F1;
- 每轮在验证集评估,`history` 记录 `val_loss / val_accuracy / val_macro_f1`;
- 产物:`outputs/bert_model/{config.json, model.safetensors, tokenizer.*, labels.json}`。

### 3. `intent/llm_router.py` — 大模型兜底

```python
class LLMIntentRouter:
    def build_zero_shot_prompt(text) / build_few_shot_prompt(text)
    def predict(self, text, mode="few_shot") -> {label, score, mode, raw}
    def mock_predict(self, text)   # 无 API Key 时的演示用兜底
```

调用协议:OpenAI 兼容 `POST {base}/chat/completions`,`temperature=0`(分类要稳),`max_tokens=16`(只要一个词)。返回的文本会做**归一化匹配**到合法意图名,匹配不上返回 `None`。

### 4. `intent/server.py` — HTTP 服务(零依赖)

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| GET | `/health` | — | `{"status":"ok","model":"bert-intent","threshold":0.8}` |
| POST | `/predict` | `{"text":"明天会下雨吗"}` | `{"text","intent","score","source","used_llm"}` |

实现用 Python 标准库 `http.server`(ThreadingHTTPServer),无第三方 Web 依赖;生产可平移替换为 FastAPI + uvicorn,接口不变。

## 四、数据流

### 训练流程(一次完整跑通)

```
load_raw() ──► make_splits() ──► save_test_set()      # 固化同一测试集
   │                │
   ├──► baselines.py  ──► train_baseline.py ──► 基线模型对比.md
   │
   └──► bert_classifier.py.train() ──► outputs/bert_model/
              │
              └──► evaluate.py ──► outputs/全方案对比.md
```

### 推理流程(服务态)

```
POST /predict {text}
   │
   ├─► IntentService.predict(text)
   │        ├─► bert.predict_proba ──► 概率分布
   │        ├─► 置信度 ≥ 阈值?  ── 是 ──► 返回 intent/source="bert"
   │        └─► 否 ──► llm_router.predict ──► 返回 intent/source="llm"
   └─► JSON 响应
```

## 五、运行指南(必须可复现)

> 所有命令在 `code/` 目录下执行;推荐用课程 `ml` conda 环境(`conda activate ml`)。

### 1. 环境
课程 `ml` 环境已内置 torch / transformers / datasets / scikit-learn / pandas。无需额外安装。

### 2. 训练基线(几秒 ~ 2 分钟,CPU)
```bash
python train_baseline.py
# 产物: outputs/test_set.json、outputs/基线模型对比.md
```

### 3. 训练 BERT(建议 GPU,CPU 亦可)
```bash
python train_bert.py --epochs 6 --batch 32 --lr 3e-5
# 产物: outputs/bert_model/、outputs/BERT训练报告.md
# 想快速验证流程: python train_bert.py --sample 2000 --epochs 3
```

### 4. 四方案对比
```bash
python evaluate.py --lstm-epochs 5
# 产物: outputs/全方案对比.md
# 已配置 LLM_API_KEY 时,会自动补上 LLM 与"混合路由"两行指标
```

### 5. 交互演示
```bash
python demo.py
# 输入 exit 退出;低置信度句子会显示"已转 LLM 兜底"
```

### 6. 启动 HTTP 服务
```bash
python serve.py --port 8000
# 另开终端验证:
curl -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" \
     -d '{"text":"明天会下雨吗"}'
```

### 7.(可选)启用真实 LLM 兜底
```bash
# Windows PowerShell 示例(硅基流动等平台取 Key)
$env:LLM_API_BASE="https://api.siliconflow.cn/v1"
$env:LLM_API_KEY="sk-xxx"
$env:LLM_MODEL="deepseek-ai/DeepSeek-V3"
python serve.py
```
> 不配置也不影响运行——服务退化为纯 BERT,演示模式会给出 mock 兜底结果。

## 七、部署形态与生产化路径

**当前(课程交付形态)**:单机、离线、纯标准库 HTTP 服务,支持并发线程。

**生产化升级路径**(文档承诺,不必在本项目实现):

| 阶段 | 动作 |
|---|---|
| 1. 框架升级 | HTTP 服务换 FastAPI + uvicorn;批量推理换 `predict_batch` + batching |
| 2. 性能 | 模型导出 ONNX / TensorRT;GPU 推理(课程笔记: vLLM/sglang 适合大模型) |
| 3. 可靠性 | 加超时/重试、限流;LLM 兜底失败时降级策略 |
| 4. 监控 | 记录意图分布、置信度分布、转 LLM 占比(成本看板) |
| 5. 数据回流 | 低置信度样本人工标注 → 增量微调 BERT(课程笔记确认: 类别增加需重新微调) |

## 八、延伸方向(面试加分项)

1. **LoRA 微调轻量 LLM**:用于把"兜底"也本地化;路线:`transformers.PeftModel` + 业务垂直数据;
2. **多意图**:一话多意图时用概率阈值**允许多个命中**(当前为 Top-1);
3. **蒸馏**:用大模型标注数据蒸馏小模型,同时压低延迟与成本;
4. **Few-Shot 自动选例**:按语义相似度动态挑选示例(而非固定抽样),提升 LLM 兜底稳定性。
