## 1. 技术选型

| 层 | 技术 | 选型理由 |
|---|---|---|
| 前端 | Streamlit（MVP）/ Vue3（V1） | Streamlit 快速验证；Vue 适合正式产品 |
| 后端 | FastAPI + uvicorn | 异步、Pydantic 校验、自动 OpenAPI |
| Agent | OpenAI Agents SDK / 自研编排 | SDK 负责工具循环，自研负责 7 步 pipeline |
| 工具协议 | FastMCP | 数据源/工具标准化接入 |
| 数据库 | SQLite（演示）/ MySQL（生产） | 演示零配置；生产成熟 |
| ORM | SQLAlchemy 2.0 | 跨库、成熟、支持反射 |
| 数据校验 | Pydantic v2 | 请求/响应/结构化输出统一 |
| SQL 解析 | sqlglot（可选） | AST 级校验，比正则可靠 |
| 缓存 | Redis | 查询结果缓存、会话缓存 |
| 可观测 | 日志 + trace | 阿里云 ARMS / Langfuse 可选 |
| 部署 | Docker Compose | 一键起前后端 + DB |

## 4. 数据库设计

### 4.1 用户与权限

```sql
CREATE TABLE users (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    user_name     TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    role          TEXT NOT NULL DEFAULT 'user',   -- admin/analyst/user
    status        BOOLEAN NOT NULL DEFAULT 1,
    created_at    DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE user_table_permission (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id    INTEGER NOT NULL REFERENCES users(id),
    table_name TEXT NOT NULL,
    UNIQUE(user_id, table_name)
);
```

### 4.2 数据源与元数据

```sql
CREATE TABLE data_sources (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL,
    type        TEXT NOT NULL,              -- sqlite/mysql
    dsn_enc     TEXT NOT NULL,              -- 加密后的连接串
    readonly    BOOLEAN NOT NULL DEFAULT 1,
    status      TEXT DEFAULT 'active',
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE table_metadata (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    source_id   INTEGER NOT NULL REFERENCES data_sources(id),
    table_name  TEXT NOT NULL,
    alias_cn    TEXT,
    description TEXT,
    updated_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(source_id, table_name)
);

CREATE TABLE column_metadata (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    table_id    INTEGER NOT NULL REFERENCES table_metadata(id),
    column_name TEXT NOT NULL,
    data_type   TEXT,
    alias_cn    TEXT,
    description TEXT,
    is_sensitive BOOLEAN DEFAULT 0,
    UNIQUE(table_id, column_name)
);

CREATE TABLE metrics (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT UNIQUE NOT NULL,
    synonyms    TEXT,                       -- 逗号分隔
    formula     TEXT NOT NULL,              -- SUM(invoices.Total)
    unit        TEXT,
    description TEXT
);
```

### 4.3 会话与消息

```sql
CREATE TABLE chat_sessions (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id     INTEGER NOT NULL REFERENCES users(id),
    session_id  TEXT UNIQUE NOT NULL,
    title       TEXT,
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE chat_messages (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    chat_id      INTEGER NOT NULL REFERENCES chat_sessions(id),
    role         TEXT NOT NULL,             -- user/assistant
    content      TEXT,
    generated_sql TEXT,
    result_json  TEXT,
    retries      INTEGER DEFAULT 0,
    elapsed_ms   INTEGER,
    created_at   DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 4.4 审计与反馈

```sql
CREATE TABLE query_logs (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id     INTEGER,
    session_id  TEXT,
    question    TEXT,
    sql_text    TEXT,
    data_source INTEGER,
    row_count   INTEGER,
    success     BOOLEAN,

CREATE TABLE feedback (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    message_id  INTEGER REFERENCES chat_messages(id),
```

## 6. Agent 设计

### 6.1 Pipeline

```python
async def run_chatbi(question, user, session):
    # 0. 权限过滤
    allowed_tables = get_allowed_tables(user)

    # 1. 意图识别
    intent = await classify_intent(question)
    if intent == "chat":
        return direct_answer(question)
    if intent == "metric_explain":
        return explain_metric(question)

    # 2. 选表
    tables = await select_tables(question, allowed_tables)

    # 3. 生成 SQL
    sql = await generate_sql(question, tables)

    # 4. 校验 + 5. 改写 + 6. 执行
    rows, sql, retries, error = await validate_rewrite_execute(
        question, tables, sql, max_retries=3
    )
    if error:
        return {"success": False, "error": error, "sql": sql}

    # 7. 汇总
    answer = await summarize(question, sql, rows)
    return {"success": True, "sql": sql, "rows": rows,
            "answer": answer, "retries": retries}
```

### 6.2 结构化输出

所有 LLM 输出都用 Pydantic 约束：

```python
class TableSelection(BaseModel):
    tables: list[str]
    reason: str

class SQLPlan(BaseModel):
    sql: str
    explanation: str
    tables: list[str]

class FinalAnswer(BaseModel):
    answer: str
    key_numbers: list[str]
    caveats: list[str]
```

### 6.3 Prompt 管理

- 所有提示词放在 `prompts/*.jinja2`，不硬编码；
- 每个 Agent 一个模板；
- 模板变量：`{{ question }}`、`{{ schema }}`、`{{ history }}`；
- 版本化管理，便于 A/B 测试。

### 6.4 重试策略

| 层级 | 条件 | 动作 |
|---|---|---|
| 1 | 静态校验失败 | 直接改写 |
| 2 | EXPLAIN 失败 | 带错误改写 |
| 3 | 执行异常 | 带错误改写 |
| 4 | 结果为空 | 改写一次（放宽条件） |
| 上限 | 3 次 | 返回失败，不编造 |

### 6.5 状态与上下文

- 会话级：最近 10 轮消息；
- 超出：用 LLM 生成摘要，替换早期消息；
- 任务级：保存 `intent`、`tables`、`sql`、`rows` 到 `chat_messages`。

## 7. SQL 安全

| 层 | 措施 |
|---|---|
| 账号 | 只读数据库账号 |
| 连接 | `PRAGMA query_only = ON`（SQLite） |
| 语句 | 只允许 `SELECT`，禁止 DDL/DML |
| 解析 | `sqlglot.parse_one()` 校验 AST |
| 表名 | 必须在授权表清单内 |
| 行数 | `LIMIT 100` + `fetchmany(100)` |
| 超时 | 查询超时 30s，超时中断 |
| 审计 | 所有 SQL 落 `query_logs` |
| 脱敏 | 敏感字段返回前脱敏 |

## 8. 语义层设计

```
业务问题
  "上个月销售额"
        ↓
语义层匹配
  销售额 → SUM(invoices.Total)
  上个月 → InvoiceDate BETWEEN ...
        ↓
生成 SQL
  SELECT SUM(Total) FROM invoices
  WHERE InvoiceDate >= '2026-09-01' AND InvoiceDate < '2026-10-01'
```

**语义层存储**：

```json
{
  "metrics": {
    "销售额": {
      "synonyms": ["营收", "流水"],
      "formula": "SUM(invoices.Total)",
      "unit": "元"
    }
  },
  "tables": {
    "invoices": {"alias": "订单", "columns": {"Total": "订单金额"}}
  }
}
```

## 9. 缓存与性能

| 缓存对象 | Key | TTL |
|---|---|---|
| Schema | `schema:{source_id}` | 1 小时 |
| 指标定义 | `metrics:{source_id}` | 1 小时 |
| 查询结果 | `query:{hash(sql)}` | 5 分钟 |
| 会话上下文 | `session:{id}` | 30 分钟 |

**性能措施**：

- 小模型路由（简单问题用 qwen-turbo，复杂问题用 qwen-max）；
- 查询结果缓存；
- 表/字段召回用向量索引，避免全量塞 prompt；
- 长对话做摘要压缩。

## 11. 评测体系

### 11.1 评测集

| 类型 | 数量 | 说明 |
|---|---|---|
| 单表查询 | 20 | 计数、筛选、排序 |
| 多表 JOIN | 20 | 外键关联 |
| 聚合分组 | 20 | GROUP BY |
| 时间范围 | 10 | 日期函数 |
| 歧义/空结果 | 10 | 考察澄清与兜底 |

### 11.2 指标

| 指标 | 计算 |
|---|---|
| 执行成功率 | 执行成功数 / 总数 |
| 结果准确率 | 结果与标准答案一致数 / 总数 |
| 平均重试次数 | 总重试 / 总请求 |
| P95 延迟 | 95 分位耗时 |
| 单次成本 | token 费用 / 请求数 |

### 11.3 回归

- 每次改 prompt / 换模型 → 跑一遍评测集；
- 记录版本号与指标，防止"改好了 A 却坏了 B"。

## 13. 风险与降级

| 风险 | 降级方案 |
|---|---|
| 模型超时 | 切小模型 / 返回缓存结果 |
| SQL 执行超时 | 中断查询，提示缩小范围 |
| 改写 3 次失败 | 返回失败原因 + SQL |
| 数据库不可用 | 健康检查 + 友好提示 |
| 成本超预算 | 限流 + 缓存 + 小模型路由 |
| 敏感数据 | 脱敏 + 权限 + 审计 |
