## 3. 核心功能详述

### F1 用户与权限

| 项 | 内容 |
|---|---|
| 目标 | 确认"谁能问什么数据" |
| 输入 | 用户名、密码 |
| 输出 | token / session |
| 流程 | 登录 → 校验密码（哈希）→ 生成 token → 后续请求带 token |
| 异常 | 用户名不存在、密码错误、账号禁用 |
| 验收 | 未登录访问业务接口返回 401；普通用户查不到无权表 |

**权限规则（MVP）**：

- 表级：用户只能查询授权表；
- 字段级：敏感字段（手机号、邮箱）默认脱敏；
- 行级（V1）：按部门/区域过滤。

---

### F2 数据源管理

| 项 | 内容 |
|---|---|
| 目标 | 接入并管理数据库 |
| 输入 | 数据源类型、连接串、只读账号 |
| 输出 | 数据源 ID、连接状态 |
| 流程 | 新增 → 测试连接 → 保存（密码加密）→ 同步元数据 |
| 异常 | 连接超时、账号无权限、驱动缺失 |
| 验收 | 能列出数据源；测试连接返回成功/失败原因 |

**注意**：必须使用**只读账号**，从源头杜绝写操作。

---

### F3 语义层

| 项 | 内容 |
|---|---|
| 目标 | 统一"业务语言 ↔ 数据库字段"的映射 |
| 输入 | 表/字段别名、指标定义、同义词 |
| 输出 | 语义配置，供选表和 SQL 生成使用 |
| 流程 | 元数据同步 → 人工补充别名/指标 → 发布 |
| 异常 | 别名冲突、指标公式非法 |
| 验收 | "销售额"能映射到 `SUM(invoices.Total)` |

**指标示例**：

| 指标 | 同义词 | 公式 | 单位 |
|---|---|---|---|
| 销售额 | 营收、流水 | `SUM(invoices.Total)` | 元 |
| 订单数 | 单量 | `COUNT(invoices.InvoiceId)` | 单 |
| 客单价 | 平均订单金额 | `SUM(Total)/COUNT(InvoiceId)` | 元 |

---

### F4 对话问答（核心）

| 项 | 内容 |
|---|---|
| 目标 | 用户提问 → 返回数据结论 |
| 输入 | `{content, user_name, session_id, options}` |
| 输出 | SSE 流：`thinking` / `sql` / `rows` / `answer` / `error` |
| 流程 | 鉴权 → 意图 → 选表 → SQL 生成 → 校验 → 改写 → 执行 → 汇总 |
| 异常 | 无权限、SQL 失败、超时、无数据 |
| 验收 | 10 题评测集执行成功率 ≥ 90% |

**交互流程**：

```
用户输入问题
   ↓ 前端显示"正在分析..."
   ↓ SSE: {"type":"thinking","text":"正在选择相关表..."}
   ↓ SSE: {"type":"sql","text":"SELECT ..."}
   ↓ SSE: {"type":"rows","data":[...]}
   ↓ SSE: {"type":"answer","text":"..."}
   ↓ 前端渲染表格 + 图表 + 回答
```

---

### F5 SQL 展示

| 项 | 内容 |
|---|---|
| 目标 | 让结果可解释、可复核 |
| 输入 | 本次查询的 SQL |
| 输出 | 代码块 + 复制按钮 |
| 规则 | 普通用户默认隐藏；分析师/管理员可见 |
| 验收 | SQL 与执行的一致；可复制 |

---

### F6 结果展示

| 项 | 内容 |
|---|---|
| 目标 | 让数据一眼看懂 |
| 输入 | 结果集（列名 + 行） |
| 输出 | 表格 / 图表 / 摘要 |
| 图表规则 | 1 个维度 + 1 个数值 → 柱状图；时间 + 数值 → 折线图；占比 → 饼图 |
| 异常 | 结果为空 → 提示"没有数据"；结果过大 → 只展示前 100 行 |
| 验收 | 表格可排序；图表可下载；空结果不报错 |

---

### F7 多轮对话

| 项 | 内容 |
|---|---|
| 目标 | 支持追问和指代 |
| 输入 | 当前问题 + 历史消息 |
| 输出 | 结合上下文的回答 |
| 策略 | 只带最近 10 轮；超出时做摘要压缩 |
| 示例 | "那上个月呢？" → 结合上一轮的维度和指标 |
| 异常 | 指代不明 → 反问澄清 |
| 验收 | 连续 3 轮追问能保持上下文 |

---

### F8 历史会话

| 项 | 内容 |
|---|---|
| 目标 | 可回看、可继续 |
| 输入 | 用户 ID |
| 输出 | 会话列表（标题、时间、消息数） |
| 操作 | 新建、切换、重命名、删除 |
| 存储 | `chat_session` + `chat_message` 两张表 |
| 验收 | 刷新页面后历史仍在；切换后可继续提问 |

---

### F9 反馈与评测

| 项 | 内容 |
|---|---|
| 目标 | 形成 Badcase 闭环 |
| 输入 | 点赞/点踩、文字反馈 |
| 输出 | 反馈记录 + 评测报表 |
| 指标 | 执行成功率、结果准确率、平均重试、P95 延迟 |
| 流程 | 用户反馈 → 标记 Badcase → 人工复核 → 补进评测集 → 回归 |
| 验收 | 每条回答可反馈；后台可按周统计 |

---

### F10 监控与审计

| 项 | 内容 |
|---|---|
| 目标 | 可观测、可追责 |
| 记录 | 用户、问题、SQL、数据源、耗时、行数、错误、token 成本 |
| 告警 | 慢查询（>10s）、错误率（>10%）、成本突增 |
| 审计 | 谁在什么时候查了什么表 |
| 验收 | 能按用户/时间/表检索日志 |

## 6. 异常与边界

| 场景 | 系统行为 |
|---|---|
| 问题与数据无关 | 直接回答"我目前只能回答数据相关问题" |
| 歧义（"最近"是多久） | 反问澄清，或按默认口径并说明 |
| 无权限表 | 拒绝并提示"无访问权限" |
| SQL 执行超时 | 中止查询，提示"查询超时，请缩小范围" |
| 结果为空 | 返回"没有查询到数据"，并展示 SQL 供核对 |
| 结果超过 100 行 | 只展示前 100 行，提示"已截断" |
| 模型服务不可用 | 降级为"请稍后重试"，记录错误 |
| 连续改写 3 次失败 | 返回失败原因 + 最后一次 SQL，不编造答案 |

## 7. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | P95 ≤ 10s（V1）；单次查询 ≤ 30s |
| 并发 | MVP 支持 20 QPS |
| 可用性 | 99.5% |
| 安全 | 只读账号、RBAC、审计、脱敏 |
| 成本 | 单次查询 ≤ 0.02 元（缓存 + 小模型路由） |
| 可维护性 | 模块化、提示词外置、可单测 |
