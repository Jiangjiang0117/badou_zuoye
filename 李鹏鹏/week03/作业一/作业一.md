### 1. langchain 工具调用 和 llm function call 有什么区别？

- **LLM function call 是模型的原生能力，LangChain 工具调用是在它之上做的统一封装 + 自动执行框架**。
- LangChain 的工具调用**依赖** LLM function calling——没有模型的 function call 能力，LangChain 的工具调用也无从谈起。
- LangChain 做的是"**统一接口 + 工具定义简化 + 自动执行循环**"这三层包装，底层调的依然是各家的 function call API。

### 2. langchain 工具调用 的 速度是受到什么影响？

- ## LLM 推理层（最主要瓶颈）

- ##  执行循环层（乘数效应，关键优化点）

- ## 工具定义层（影响每轮输入长度）

- ## 回传内容层（滚雪球效应）

- ## 框架与网络层（通常可忽略）
