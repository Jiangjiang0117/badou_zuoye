> 定位：研发级设计，回答“模块怎么拆、接口怎么定、SQL 怎么安全执行、怎么评测”。

### 1. 总体架构
- 接入层：Web/IM/API。
- 对话层：会话管理、上下文、意图识别。
- Agent 编排层：规划器、工具路由器、执行器、反思/重试。
- 语义层：指标、维度、同义词、口径、默认过滤。
- 检索层：元数据/文档/历史问答向量检索。
- 查询层：DSL/SQL 生成、校验、执行、结果处理。
- 治理层：权限、审计、脱敏、限流、成本。
- 观测层：日志、Trace、指标、评测。

### 2. 核心模块设计
- **会话服务**：会话状态、上下文窗口、指代消解。
- **语义服务**：指标解析、维度解析、时间解析、同义词映射。
- **Agent 编排**：任务分类、计划生成、工具调用、失败重试、降级。
- **查询服务**：Text2DSL/Text2SQL、SQL AST 校验、权限注入、沙箱执行。
- **可视化服务**：图表推荐、配置生成。
- **评测服务**：评测集、自动评测、回归测试、badcase 回流。

### 3. 关键流程设计
建议画时序图：
1. 用户提问 → 意图识别 → 语义解析 → 澄清/计划 → 工具调用 → SQL 校验 → 执行 → 结果验证 → 图表/结论 → 审计。
2. 权限流程：用户身份 → 权限策略 → 查询前注入 → 查询后过滤 → 审计。
3. 失败重试：SQL 错误 → 错误分类 → 自动修正 → 限次重试 → 降级提示。

### 4. 数据与存储设计
- 会话表、消息表、查询日志表、反馈表、语义配置表、审计表、评测集表。
- 向量库：指标/字段/文档/历史问答。
- 缓存：元数据缓存、查询结果缓存、语义解析缓存。

### 5. 接口设计
- `/chat` 对话接口
- `/semantic/resolve` 语义解析
- `/query/execute` 查询执行
- `/chart/recommend` 图表推荐
- `/feedback` 反馈
- `/admin/semantic` 语义管理
- 统一响应：答案、图表、口径、SQL、置信度、traceId、权限提示。

### 6. SQL 安全与准确性设计
- 只读账号、白名单、AST 校验、禁止 DDL/DML。
- 行数/超时/代价限制、分区裁剪、全表扫描拦截。
- 权限注入：行级/列级/指标级。
- 结果校验：空值、异常波动、口径冲突、置信度。
- 可解释：展示查询计划/SQL/口径/数据时间。

### 7. 模型与 Prompt 设计
- 模型路由：简单解析小模型、复杂规划大模型、规则兜底。
- Prompt 版本管理、结构化输出、JSON Schema 校验。
- 上下文压缩、敏感信息过滤、Prompt 注入防护。

### 8. 评测与可观测
- 评测集：问题、标准指标、标准 SQL/结果、权限用例。
- 指标：意图准确率、语义解析准确率、SQL 执行成功率、结果正确率、首响、成本。
- Trace：请求链路、Prompt、工具调用、SQL、耗时、token。
- 告警：错误率、慢查询、越权、成本异常。

### 9. 部署与运维
- 服务拆分、容器化、配置中心、灰度发布。
- 限流降级、灾备、日志留存、审计合规。

### 10. 技术验收
- 压测、权限渗透测试、SQL 注入测试、评测集回归、故障演练。
