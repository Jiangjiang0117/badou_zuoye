# ChatBI 自助问数系统 功能设计文档

**版本**：v1.0（与项目设计文档 v1.0 对齐）  
**阶段**：MVP 功能设计  
**适用范围**：4 指标、20 张 MySQL 表、单表为主、1 个月交付  
**文档用途**：开发任务拆分、测试用例设计、验收对照

---

## 1. 文档说明

### 1.1 设计范围

本文档描述 MVP 首期**功能层面**的设计，包括功能清单、功能编号、角色权限、主流程、业务规则、异常处理、界面要素、接口映射与状态机。技术架构、语义层表结构、部署拓扑以《项目设计文档 v1.0》为准，本文档不重复展开。

### 1.2 功能设计原则

- **功能可验收**：每个功能编号对应可测试的输入、处理、输出与异常。
- **范围冻结**：只设计首期已确认功能，不引入 Data Agent 多步执行、自动报表、外部集成、行列权限。
- **质量机制内嵌**：自动校验与抽检不是附属功能，而是问数主链路和回答状态的组成部分。
- **做减法**：每个功能只做最小可用闭环，报告导出、抽检工作台、配置管理均按 MVP 裁剪。

### 1.3 角色定义

| 角色 | 标识 | 功能范围 |
| :--- | :--- | :--- |
| 业务用户 | `business_user` | 登录、对话问数、查看回答、导出报告、查看历史 |
| 分析师 | `analyst` | 业务用户全部功能 + 抽检工作台 + 配置管理 + 测试集跑批 |

## 3. M1 认证与角色功能设计

### F-M1-01 用户登录

| 项 | 内容 |
| :--- | :--- |
| 角色 | 全部 |
| 前置条件 | 用户账号已创建并分配角色 |
| 输入 | 用户名、密码 |
| 主流程 | 提交凭证 → 校验 → 创建会话 → 按角色跳转首页 |
| 业务规则 | 密码错误提示不区分“用户不存在/密码错误”；连续失败 5 次锁定 10 分钟（MVP 可简化为提示） |
| 异常 | 凭证错误、账号禁用、会话创建失败 |
| 输出 | 登录态 Token/会话 Cookie，返回角色与可访问菜单 |
| 界面要素 | 用户名输入、密码输入、登录按钮、错误提示区 |
| 接口 | `POST /api/auth/login` |
| 验收关联 | 登录与双角色可用 |

### F-M1-02 角色识别与功能可见性控制

| 项 | 内容 |
| :--- | :--- |
| 角色 | 全部 |
| 主流程 | 登录后读取角色 → 前端按角色渲染菜单 → 后端接口按角色鉴权 |
| 业务规则 | `business_user` 不可见抽检、配置、测试集、日志菜单；直接调用分析师接口返回 403 |
| 界面要素 | 顶部导航按角色显示“对话”“历史”“抽检”“配置”“评测”入口 |
| 接口 | 所有接口统一角色中间件 |
| 验收关联 | 双角色功能边界可验证 |

### F-M1-03 退出登录与会话失效

| 项 | 内容 |
| :--- | :--- |
| 主流程 | 点击退出 → 销毁会话 → 跳转登录页 |
| 业务规则 | 会话超时默认 8 小时；失效后访问受保护页面跳登录 |

## 4. M2 对话问数功能设计

### 4.1 问数主流程（功能串联）

```
F-M2-01 提问
  → F-M2-02 意图解析与 DSL 生成
  → F-M2-03 DSL 合法性校验
      ├─ 不合法 → F-M2-09 无法回答/降级
      └─ 合法 → F-M2-04 语义编译
          → F-M2-05 SQL 执行与护栏
              ├─ 执行失败 → F-M2-07 重试一次
              └─ 成功 → F-M2-06 自动校验
                  ├─ 通过 → F-M2-08 展示 + F-M2-10 低置信度标记
                  └─ 不通过 → F-M2-07 重试一次 → 仍失败 → F-M2-09
```

### F-M2-01 自然语言提问

| 项 | 内容 |
| :--- | :--- |
| 角色 | 业务用户、分析师 |
| 输入 | 文本问题，长度限制 500 字 |
| 主流程 | 输入问题 → 可选附带会话上下文 → 提交问数接口 |
| 业务规则 | 空问题不允许提交；单次只处理一个问题；首期不支持上传文件或图片 |
| 异常 | 空输入、超长、会话不存在、频率超限 |
| 界面要素 | 对话输入框、发送按钮、示例问题提示、加载态 |
| 接口 | `POST /api/chat/query` |
| 数据依赖 | 会话表、问数记录表 |
| 验收关联 | 业务用户可完成自助问数 |

### F-M2-02 意图解析与 DSL 生成

| 项 | 内容 |
| :--- | :--- |
| 角色 | 系统 |
| 前置条件 | 问题非空；语义配置已加载 |
| 主流程 | 同义词/指标/维度召回 → 组装提示词 → LLM 输出 DSL JSON → 解析 |
| DSL 字段 | `metric`、`dimensions`、`filters`、`time_range`、`chart_hint` |
| 业务规则 | 模型只允许“选词填空”，不得输出表名、Join 条件、原生 SQL；`metric` 必须来自召回候选；维度必须已登记；时间范围必填或可推导 |
| 异常 | LLM 超时、返回非 JSON、字段缺失、指标不在候选 |
| 输出 | 结构化 DSL 或解析失败原因 |
| 数据依赖 | `sl_metric`、`sl_dimension`、`sl_synonym` |
| 验收关联 | 首答可用率、DSL 合法性 |

### F-M2-03 DSL 合法性校验

| 项 | 内容 |
| :--- | :--- |
| 角色 | 系统 |
| 主流程 | Schema 校验 → 指标存在性 → 维度合法性 → 过滤字段合法性 → 时间范围合法性 → Join 路径可行性预检 |
| 业务规则 | 任一不通过即拒绝进入编译；不合法原因需可读 |
| 异常 | 未登记指标、维度不支持、过滤字段非法、时间缺失、关联路径未登记 |
| 输出 | 合法/不合法 + 原因码 |
| 验收关联 | 自动校验覆盖率、无法回答原因可解释 |

### F-M2-04 语义编译生成 SQL

| 项 | 内容 |
| :--- | :--- |
| 角色 | 系统 |
| 前置条件 | DSL 合法 |
| 主流程 | 查指标与默认口径 → 判断是否命中基准 SQL 模板 → 命中则参数化复用，未命中则固定模板拼装 → 注入护栏 |
| 业务规则 | 口径 `WHERE` 条件不得被模型改写；仅允许 `sl_join_path` 登记路径；强制时间条件、`LIMIT`、禁止 `SELECT *`、禁止明细无聚合查询 |
| 异常 | 模板参数缺失、Join 路径缺失、护栏注入失败 |
| 输出 | 可执行 SQL + 编译元信息（命中模板/即席拼装、使用口径版本） |
| 数据依赖 | `sl_metric`、`sl_metric_caliber`、`sl_join_path` |
| 验收关联 | 口径正确率、首答可用率 |

### F-M2-05 SQL 执行与护栏

| 项 | 内容 |
| :--- | :--- |
| 角色 | 系统 |
| 主流程 | 只读账号执行 → 超时控制 → 行数限制 → 结果返回 |
| 业务规则 | 执行超时 5 秒；返回行数上限 1000；禁止访问系统表；并发按单实例限制 |
| 异常 | 超时、语法错误、权限错误、结果超限、连接失败 |
| 输出 | 结果集或错误码 |
| 验收关联 | 可用性、护栏有效性 |

### F-M2-06 自动校验四层

| 层级 | 功能规则 | 失败处理 |
| :--- | :--- | :--- |
| L1 语法与安全 | 仅 SELECT；AST 校验；关键字白名单；禁止 DDL/DML；禁止过深嵌套 | 拦截，不展示 |
| L2 可执行性 | SQL 可执行、未超时、扫描行数可控 | 触发一次重试 |
| L3 结果合理性 | 结果非空或有合理空结果说明；指标值域合理（收入≥0、转化率 0–1）；时间范围与问题匹配；行数不超限 | 标记低置信度或拦截 |
| L4 口径一致性 | 命中基准模板时自动执行基准 SQL 比对；容差可配置 | 不一致则拦截，转人工确认 |

| 项 | 内容 |
| :--- | :--- |
| 角色 | 系统 |
| 业务规则 | 四层全部通过才展示确定性答案；L4 不通过不得展示为确定答案 |
| 输出 | 校验通过/拦截 + 层级 + 原因 |
| 验收关联 | 展示前自动校验覆盖率 100% |

### F-M2-07 失败重试（最多一次）

| 项 | 内容 |
| :--- | :--- |
| 角色 | 系统 |
| 触发 | SQL 执行失败或自动校验不通过 |
| 主流程 | 携带错误信息回传 LLM → 修正 DSL → 重新编译执行校验 |
| 业务规则 | 仅允许一次；重试回答不计入首答分母；重试仍失败返回无法回答 |
| 异常 | 重试仍失败、重试超时 |
| 输出 | 重试结果与重试日志 |
| 验收关联 | 首答可用率分母口径、重试成功率 |

### F-M2-08 回答展示（图表+结论+口径说明）

| 项 | 内容 |
| :--- | :--- |
| 角色 | 业务用户、分析师 |
| 输入 | 校验通过的结果集、DSL、编译元信息、口径配置 |
| 主流程 | 按维度数量选图表 → 生成简短结论 → 展示口径说明 → 展示置信度标签 |
| 图表规则 | 0 维单值 → 指标卡；1 维 → 柱状图/折线图（时间维度用折线）；2 维及以上 → 首期降级为表格或提示收窄维度 |
| 结论规则 | 只基于本次结果生成，不编造未查询数据；包含时间范围、过滤条件、Top/Bottom 描述 |
| 口径说明 | 指标定义、基准 SQL 版本、数据时间范围、过滤条件、更新时间 |
| 界面要素 | 图表区、结论区、口径说明折叠区、置信度标签、导出按钮、反馈入口 |
| 接口 | 问数响应体 |
| 验收关联 | 回答完整性、口径可解释 |

### F-M2-09 无法回答与降级提示

| 项 | 内容 |
| :--- | :--- |
| 角色 | 业务用户、分析师 |
| 触发 | DSL 不合法、编译失败、重试仍失败、口径拦截 |
| 输出 | 明确原因：未登记指标、维度不支持、超出范围、校验未通过、执行失败、需人工确认 |

| 验收关联 | 异常可解释、不产生未校验答案 |

### F-M2-10 低置信度标记

| 项 | 内容 |
| :--- | :--- |
| 角色 | 系统 |
| 触发条件 | 未命中基准模板、经过重试、L3 存疑、即席组合 |

| 验收关联 | 抽检抽样有效性 |

### F-M2-11 多轮上下文指代（有限）

## 6. M4 分析师抽检功能设计

### 6.1 抽检状态机

```
回答已展示
  → 进入抽检池：待抽检
      ├─ 抽检通过 → 已抽检（计入正确率样本）
      └─ 发现问题 → 已更正 / 已撤回（记录问题类型，进入修复队列）
  → 未被抽中 → 保持已展示（仍可手动加抽）
```

### F-M4-01 待抽检列表

## 12. 关键状态机

### 12.1 回答状态

```
生成中 → 已校验通过（展示）
      → 已拦截（不展示确定性答案）
      → 重试中 → 已校验通过 / 无法回答
已展示 → 待抽检 → 已抽检
                → 已更正
                → 已撤回
```

### 12.2 抽检状态

```
待抽检 → 已抽检（通过）
       → 已更正（发现问题并更正）
       → 已撤回（发现问题并撤回）
```

### 12.3 配置版本状态

```
草稿 → 生效（默认口径唯一）→ 已停用
生效变更 → 新版本生效，旧版本保留可追溯
```
