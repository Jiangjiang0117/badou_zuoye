## 1. 功能总览

按用户视角，ChatBI 提供四大入口功能 + 三大支撑功能：

| 编号 | 功能模块 | 类型 | 优先级 |
|---|---|---|---|
| F1 | 自然语言问数 | 核心 | P0 |
| F2 | 多轮对话与追问 | 核心 | P0 |
| F3 | 结果呈现与可视化 | 核心 | P0 |
| F4 | 数据洞察与归因 | 核心（二期增强） | P1 |
| F5 | 指标语义层（口径管理） | 支撑 | P0 |
| F6 | 权限与安全 | 支撑 | P0 |
| F7 | 反馈闭环与评测 | 支撑 | P1 |

## 2. F1 自然语言问数

### 2.1 功能描述
用户输入一句自然语言问题，系统返回「结论（自然语言）+ 数据表格 + 图表 + 可查看的 SQL/口径」，并附带置信度/过程解释。

### 2.2 用户故事
> 作为运营，我想输入「上个月各渠道的 GMV 和环比」，希望直接看到各渠道 GMV 表格和涨跌对比图，而不是自己写 SQL。

### 2.3 输入 / 输出

- **输入**：自然语言问题（中文为主）。
- **输出**：Answer 对象，含
  - `answer_text`：一句话结论（含关键数字）
  - `table`：查询结果表格
  - `chart`：自动推荐的图表（类型 + 配置）
  - `sql`：最终执行的 SQL（可折叠，供审计）
  - `metric_def`：命中的指标口径（若有）
  - `confidence`：置信度（高/中/低）

### 2.4 处理流程（对应课程 7 阶段）

```
输入问题 → [意图识别] → [指标/实体链接] → [表选择] → [SQL生成]
         → [SQL校验(硬校验+语义)] → [改写(最多N次)] → [权限注入+只读执行]
         → [结果解读+选图] → 输出
```

### 2.5 功能子项

| 子项 | 说明 | 验收标准 |
|---|---|---|
| 意图识别 | 区分「问数 / 元数据咨询 / 闲聊 / 操作指令」 | 问数类正确进入链路，闲聊友好拒绝 |
| 实体链接 | 把口语中的词映射到 表/字段/指标/维度/过滤值 | 同义词（如「营收」「收入」→ `revenue`）命中 |
| 指标路由 | 命中官方指标时直接用指标定义生成 | 口径一致，不重写计算逻辑 |
| SQL 生成约束 | 只 SELECT、用真实表/字段、正确 JOIN | 无幻觉字段，多表 JOIN 正确 |
| 元数据类问题 | 「有哪些表」「活跃用户怎么定义」 | 直接由元数据/语义层回答，短路 SQL 链路 |

### 2.6 边界与异常
- 无法识别意图 → 引导澄清，不给错误答案。
- 生成 SQL 连续 N 次校验失败 → 返回「暂时无法回答 + 原因 + 建议改写的问题」。
- 结果为空 → 明确说明「没有查到相关数据」。

## 3. F2 多轮对话与追问

### 3.1 功能描述
在多轮对话中，用户可在上一问基础上追加/修改条件、切换维度、改时间范围，系统结合上下文理解（含指代消解）。

### 3.2 典型对话

```
用户：上个月 GMV 多少？
系统：上个月 GMV 为 1.2 亿，环比 +8%。
用户：按渠道拆一下           → 理解「仍指上个月 GMV」，按渠道分组
用户：只看华东区             → 追加过滤条件
用户：换成毛利                → 切换指标，保留维度与时间
```

### 3.3 上下文状态机
- 维护 `Context { 指标, 维度[], 过滤[], 时间范围 }`，每次问答后增量更新。
- 支持条件**追加 / 修改 / 撤销**（如「去掉华东区」）。

### 3.4 验收标准
- 指代消解正确率（「它」「这个」「上一问」）≥ 90%。
- 切换维度/指标时，正确保留未变更的上下文。
- 用户可显式「清空上下文 / 开新话题」。

## 4. F3 结果呈现与可视化

### 4.1 功能描述
把查询结果组织为「结论 + 表格 + 图表」，图表类型由数据形态自动选择。

### 4.2 图表自动选择规则

| 数据形态 | 推荐图表 |
|---|---|
| 时间序列 | 折线图 |
| 占比/构成 | 饼图/环形图 |
| 类别对比 | 柱状图/条形图 |
| 两个变量的关系 | 散点图 |
| 地域分布 | 地图 |

### 4.3 交互
- 表格支持排序、筛选、导出（CSV/Excel）。
- 图表支持切换类型、下钻维度。
- 「查看 SQL」与「查看口径」可展开，保证可解释、可审计。

### 4.4 验收标准
- 单值结果给 KPI 卡；时序给折线；占比给饼；对比给柱。
- 大数据量（> 阈值）自动降采样/分页，不卡死前端。

## 5. F4 数据洞察与归因（P1）

### 5.1 功能描述
不只给数，还给「读」——自动解读结果，检测异常，给出可能原因。

### 5.2 子能力

| 子能力 | 说明 |
|---|---|
| 结果解读 | 把数字转成业务结论（「同比上升 8%，主要由华东区拉动」） |
| 异动检测 | 对时序指标做异常检测（阈值/算法），主动提示「今天点击量异常下跌」 |
| 归因分析 | 异常时按维度下钻，找主要贡献维度（如「下跌集中在 iOS 渠道」） |
| 报告生成 | 将一轮问答沉淀为可分享的分析报告（结论+图表+口径） |

### 5.3 验收标准（二期）
- 异动检测召回率、归因 Top1 命中率达到评测基线（数值按数据定）。
- 报告可导出、可分享，含口径说明。

## 6. F5 指标语义层（口径管理）

### 6.1 功能描述
提供「指标 / 维度 / 口径」的统一管理，让问数结果口径一致、可复用、可治理。**这是可信问数的基石。**

### 6.2 核心对象

| 对象 | 字段 | 示例 |
|---|---|---|
| 指标 Metric | 名称、同义词、口径（计算公式）、聚合方式、所属主题域、负责人 | `GMV`：sum(订单金额)，同义词[成交额, 销售额] |
| 维度 Dimension | 名称、同义词、所属表/字段 | `渠道`：channel，同义词[来源, 渠道来源] |
| 过滤条件 Filter | 名称、映射 | `华东区`：region in (上海,江苏,浙江,安徽,福建,江西,山东) |
| 数据字典 Dict | 字段→同义词→示例值 | `country`：国家，示例[USA, Canada] |

### 6.3 功能子项
- 指标/维度/同义词的增删改查与审核（口径变更需审批）。
- 指标路由：问数命中指标时，优先用官方口径生成，避免各写各的 SQL。
- 口径问答：「XX 怎么定义」直接返回口径说明。
- 版本管理：口径变更留痕，历史问答可追溯到当时口径。

### 6.4 验收标准
- 高频指标覆盖 ≥ 60%。
- 同一问数在两次不同措辞下命中同一口径。

## 7. F6 权限与安全

### 7.1 功能描述
问数结果必须与用户在数仓中的权限对齐，敏感数据不可越权可见。

### 7.2 权限模型
- 对齐数据源原生权限（用户/角色 → 库/表/行/列）。
- 执行 SQL 前注入权限过滤（行级 RLS、列级 CLS）。
- 敏感字段（如薪资、手机号）自动识别 + 拦截或脱敏。

### 7.3 SQL 安全
- 只读白名单：仅允许 `SELECT/WITH/PRAGMA/EXPLAIN`，拒绝一切写操作。
- 高危关键字/语法拦截（`INSERT/UPDATE/DELETE/DROP/ALTER/ATTACH`）。
- 超时与并发控制，防止慢查询拖垮库。

### 7.4 验收标准
- 越权查询返回空/拒绝，不泄露任何列。
- 写操作 100% 被拦截。
- 敏感字段输出前脱敏。

## 8. F7 反馈闭环与评测

### 8.1 功能描述
收集用户对答案的反馈（采纳/点赞/点踩 + 纠错），沉淀为 Few-shot 与口径改进，并持续评测准确率。

### 8.2 闭环流程

```
用户反馈(点赞/点踩/纠错) → 人工复核 → 沉淀Few-shot/修正同义词或口径
                                    → 更新评测集 → 回归评测 → 上线
```

### 8.3 评测体系
- **评测集**：真实问题 + 标准 SQL/标准答案（人工标注）。
- **评测指标**：语义准确率（执行结果一致）、口径命中率、端到端正确率。
- **回归**：口径/模型/提示词变更后自动跑评测集。

### 8.4 验收标准
- 反馈入口可见，点踩后有纠错通道。
- 每周产出准确率看板。

## 9. 非功能需求（摘要）

| 类别 | 要求 |
|---|---|
| 性能 | 端到端 P95 ≤ 10s，缓存命中 ≤ 2s |
| 可用性 | 服务可用性 ≥ 99.9% |
| 安全 | 传输加密、数据只读、审计留痕 |
| 合规 | 支持数据不出域/私有化部署（可选） |
| 可观测 | 全链路日志、Trace、成本与延迟监控 |
