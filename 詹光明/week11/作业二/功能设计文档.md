*MVP 功能模块、交互流程、异常处理与验收用例*

版本：0.1（设计基线草案） \| 状态：待业务试点与技术验证后基线化

# 1. 文档范围

本文描述用户可见功能、后台管理功能、Agent
任务流程、关键交互状态、异常策略和功能验收。设计以部门级内网 MVP
为目标，首个业务域采用可配置方式接入。

# 2. 用户角色与权限

  ----------------------------------------------------------------------------------------------
  角色                                权限范围
  ----------------------------------- ----------------------------------------------------------
  普通业务用户                        发起分析、查看本人有权访问的数据、查看本人会话与分析记录

  业务分析师                          普通用户能力；在授权范围内查看
                                      SQL/参数，维护或审核业务语义（需额外授权）

  数据管理员                          配置数据源、选择授权表字段、维护语义层、配置行级策略

  系统管理员                          用户角色管理、系统配置、运行状态、审计日志和安全策略管理
  ----------------------------------------------------------------------------------------------

权限应遵循最小授权原则。角色是功能权限，行级策略是数据范围权限，二者分别校验。

# 4. 主要用户流程

## 4.1 简单问数流程

1.  用户输入问题，例如"上个月各渠道的订单金额是多少"。

2.  系统识别指标、时间范围、维度与必要筛选条件。

3.  从语义层解析指标定义、表关系、可用字段和权限范围。

4.  生成查询计划与 SQL，执行静态安全校验和权限策略校验。

5.  通过只读数据库连接执行查询，限制执行时间、扫描规模和结果行数。

6.  对结果进行类型检查和基础统计，选择表格或适合的基础图表。

7.  返回结果、口径说明和可展开的分析详情，并将任务与审计信息关联保存。

## 4.2 复杂经营分析流程

8.  解析用户目标，识别指标、分析对象、时间范围、比较基准和缺失条件。

9.  若业务口径或关键条件存在歧义，向用户提出最少量澄清问题。

10. Agent
    生成结构化分析计划，例如：计算目标期与基准期、计算变化量、按维度拆解、计算贡献度、检查结果一致性。

11. 计划校验器检查步骤是否在允许的分析模板和工具范围内；必要时限制或拒绝不合理步骤。

12. Agent
    逐步调用只读查询工具；每一步保存输入、SQL、参数、结果摘要和状态。

13. 分析器计算同比/环比、维度差异和贡献度；校验分母为零、缺失值、口径不一致等情况。

14. 若中间结果不足以支撑结论，Agent
    可以在预算内追加查询，或停止并说明限制。

15. 生成结果摘要、图表、贡献维度、证据引用和后续建议；不把相关性自动表述为因果关系。

# 5. 分析能力定义

## 5.1 同比/环比

-   同比：当前周期指标与上年相同周期比较；环比：当前周期与上一个可比周期比较。

-   系统必须明确周期边界、时区、日期字段、是否使用完整周期以及指标口径。

-   变化量 = 当前值 - 基准值；变化率 = (当前值 - 基准值) / 基准值。

-   基准值为零或缺失时，不计算常规百分比，展示"不可计算"并说明原因。

-   对非完整周期数据，应标记部分周期或按明确规则进行同长度比较。

## 5.2 多维度下钻

-   从总体指标下钻至已配置的维度，例如区域、渠道、产品或客户分层。

-   仅允许使用语义层已授权的维度和表关联。

-   每次下钻保留原有时间范围与筛选条件，除非用户明确修改。

-   支持返回上层视图，并展示当前分析路径和过滤条件。

## 5.3 贡献度分析

-   将总体指标变化拆解为各维度成员的变化贡献，展示绝对变化量和贡献占比。

-   若正负贡献并存，明确展示抵消效应；贡献占比的分母接近零或总体变化为零时，应避免误导性百分比。

-   聚合结果与总体变化应执行一致性校验；不一致时说明舍入、缺失类别或口径原因。

-   贡献度表示统计拆解，不等于因果影响。

# 6. 语义层功能

-   指标定义：名称、业务描述、计算表达式/聚合方式、单位、默认过滤、时间字段、负责人、审核状态。

-   维度定义：名称、来源字段、数据类型、可用范围、同义词和排序规则。

-   表关系：主外键或经审核的关联表达式、关联类型、唯一性预期和风险提示。

-   业务术语：将自然语言别名映射到指标、维度或筛选值。

-   语义状态：草稿、待审核、已发布、已停用；默认只允许已发布定义用于权威分析。

-   版本记录：修改人、时间、变更内容；历史任务应保存当时使用的语义版本标识。

# 7. 分层透明与结果页面

  ---------------------------------------------------------------------------------------------------------
  层级                                默认展示内容
  ----------------------------------- ---------------------------------------------------------------------
  结果层                              自然语言结论、主要指标、图表/表格、时间范围和数据更新时间（若可得）

  依据层                              关键比较值、变化量、贡献维度、指标口径和分析步骤摘要

  执行层                              SQL、参数、查询耗时、结果行数、语义版本与执行状态

  诊断层                              错误类型、可理解原因、已尝试的恢复动作、建议的下一步
  ---------------------------------------------------------------------------------------------------------

SQL 参数展示需避免泄露敏感值；普通用户是否可见完整 SQL
应由产品权限配置控制。不得向用户展示模型的隐式内部推理链。

# 8. 会话与上下文

-   MVP 支持当前会话内的指标、时间、维度、过滤条件和分析结果引用。

-   用户追问"那同比呢"时，应继承可明确解析的上文条件，并在结果中显示实际继承的条件。

-   遇到"去年""上个月"等相对时间表达时，按企业时区解析并将具体日期范围展示给用户。

-   会话上下文不能作为权限来源；每一次查询均重新执行当前用户权限校验。

-   跨会话长期记忆、个人偏好画像和团队共享分析模板暂不纳入 MVP。

# 9. 异常处理与产品反馈

  -------------------------------------------------------------------------------------------------------------
  场景                    系统行为                                             用户反馈
  ----------------------- ---------------------------------------------------- --------------------------------
  业务歧义                停止生成权威查询，提出聚焦澄清问题                   指出歧义项和可选解释

  权限拒绝                立即阻断，不通过改写提示词绕过                       说明无权访问该数据或联系管理员

  SQL 校验失败            拒绝执行，记录原因；仅允许安全的受控修正             说明查询不符合安全规则

  数据库超时/暂时错误     有限次数重试，遵守总任务预算                         说明失败阶段与是否可重试

  空结果                  检查时间范围、过滤条件与数据可用性，不擅自扩大权限   说明当前条件下无匹配数据

  指标定义缺失            请求用户选择已知指标或提示管理员补充语义             不猜测并冒充权威口径

  证据不足/结果冲突       停止强归因，标注限制并给出可验证的下一步             区分事实、推测和未知项
  -------------------------------------------------------------------------------------------------------------

# 10. 功能验收用例

  -----------------------------------------------------------------------------------------------------
  编号                    验收场景                     预期结果
  ----------------------- ---------------------------- ------------------------------------------------
  F-01                    查询已发布指标并按维度分组   SQL 通过校验，返回与基准 SQL 一致的结果

  F-02                    追问同一指标的同比           继承正确筛选条件，明确展示比较周期

  F-03                    下钻后继续追问环比           保留既有条件并正确更新周期

  F-04                    对总体变化做贡献度拆解       贡献结果可复算，并对零分母和正负贡献做说明

  F-05                    用户尝试查询未授权区域       服务端阻断或强制施加可信行级约束，不能越权返回

  F-06                    问题包含未知指标别名         请求澄清或提示语义未配置，不擅自采用近似指标

  F-07                    SQL 包含写操作或多语句       拒绝执行并记录安全事件

  F-08                    数据库超时                   在预算内有限重试，最终给出明确错误反馈

  F-09                    展开执行详情                 显示正确 SQL、参数、口径、结果摘要和任务关联标识

  F-10                    用户无权查看 SQL 详情        隐藏或脱敏执行信息，但不影响结果权限校验
  -----------------------------------------------------------------------------------------------------
