## 作业1: 安装langchain 和 openai-agent，运行 langchain / 02_Model工具调用.py。回答如下问题：
### 一、langchain 工具调用 和 llm function call 有什么区别？
1. tools的编写方式不同
    - llm function call需要手动编写工具列表，以及其中每个工具的json
    - langchain只需要编写工具内部逻辑，封装成函数，再加上@tool装饰器即可。@tool装饰器会自动将函数转换为json格式的工具。
2. 调用过程不同
    - llm function call需要手动对响应结果进行解析，判断模型是否调用了工具，然后运行工具，将工具运行的结果发给模型。对于过程中的异常报错需要手动捕获处理。
    - langchain会自动对模型的响应结果进行解析，判断模型是否调用了工具，然后运行工具，最后将用户提问、工具选择、工具运行结果全部加入消息列表发给模型进行汇总。
3. 调用多个工具的处理方式不同
    - llm function call是一次请求一次工具调用，每次工具调用完成后将结果发给模型，再根据模型的响应结果来调用下一次工具。
    - langchain会自动对模型的响应结果进行解析，判断模型是否调用了多个工具，然后运行每个工具，将工具运行的结果一次性加到消息列表发给模型。


### 二、langchain 工具调用 的 速度是受到什么影响？
1. 可能受工具执行的并行串行影响，多个工具并行执行一般比串行更快
2. 可能受模型的响应速度、网络延迟影响
3. 可能受设置的模型参数影响，例如thinking、temperature等
