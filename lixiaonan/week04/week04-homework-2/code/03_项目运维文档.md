## 二、环境依赖

### 2.1 基础环境

| 组件 | 版本要求 |
|---|---|
| Python | >= 3.10 |
| CUDA | >= 11.8（GPU 推理） |
| Neo4j | >= 5.x |
| Milvus | >= 2.3 |
| Redis | >= 7.x（对话缓存） |

### 2.2 Python 依赖包

```bash
# 核心依赖
pip install torch transformers
pip install neo4j                  # 图数据库客户端
pip install pymilvus               # 向量数据库
pip install rank_bm25              # BM25 检索
pip install fastapi uvicorn        # API 服务
pip install openai                 # Deepseek API 兼容接口
pip install redis                  # 对话缓存
```

## 三、服务启动与配置

### 3.1 Neo4j 知识图谱服务

```bash
# 启动 Neo4j
neo4j start

# 验证连接
cypher-shell -u neo4j -p <password> "MATCH (n) RETURN count(n)"

# 预期输出：31680（实体节点数量）
```

### 3.2 向量数据库（Milvus）

```bash
# 使用 Docker 启动 Milvus
docker-compose up -d milvus

# 验证向量集合
python -c "from pymilvus import connections; connections.connect(); print('Milvus OK')"
```

### 3.3 NLU 意图识别服务

```bash
# 启动意图识别模型服务
python src/nlu_service.py --model_path ./models/intent_classifier --port 8001

# 健康检查
curl http://localhost:8001/health
```

### 3.4 主 API 服务

```bash
# 启动主问答 API
uvicorn src.main:app --host 0.0.0.0 --port 8000 --workers 4

# 测试接口
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"session_id": "test_001", "message": "我的订单什么时候发货？"}'
```

## 五、知识图谱运维

### 5.1 知识更新流程

```
业务数据更新（新品上架/政策变更）
    │
    ▼
数据清洗与实体识别（NER 模块）
    │
    ▼
三元组抽取与质量校验
    │
    ▼
增量写入 Neo4j（不影响线上服务）
    │
    ▼
向量重新编码 → 更新 Milvus
    │
    ▼
灰度验证（小流量测试）→ 全量上线
```

### 5.2 定期维护任务

| 任务 | 频率 | 说明 |
|---|---|---|
| 知识图谱增量更新 | 每天 02:00 | 同步最新商品/政策数据 |
| 向量索引重建 | 每周日 03:00 | 优化检索性能 |
| 模型效果评估 | 每周一 | 抽样评测准确率 |
| 错误日志分析 | 每天 | 分析未识别意图，准备补标数据 |
| 数据库备份 | 每天 | Neo4j + 向量数据库备份 |

## 六、故障排查

### 6.1 常见问题

**问题1：意图识别准确率下降**
```
排查步骤：
1. 检查近期是否有新词汇/新业务未纳入训练集
2. 查看错误日志中高频未识别问题
3. 补充标注数据，触发模型增量训练
4. 灰度验证后上线新模型
```

**问题2：响应时间超时**
```
排查步骤：
1. 检查 Deepseek API 延迟（外部依赖）
2. 检查 Neo4j 查询是否存在慢查询（>500ms）
3. 检查 Milvus 向量检索性能
4. 检查 Redis 缓存命中率，考虑扩大缓存
```

**问题3：知识图谱查询无结果**
```
排查步骤：
1. 确认 Neo4j 服务正常运行
2. 检查实体识别是否正确抽取关键实体
3. 验证实体在图谱中是否存在（可能是新品未录入）
4. 触发知识更新流程
```

## 七、数据安全与合规

- 用户对话数据脱敏后存储，保留 90 天
- 敏感词过滤（用户个人信息、竞品词）
- API 接口限流：单用户 100 次/分钟
- 日志审计：保留 180 天操作日志
