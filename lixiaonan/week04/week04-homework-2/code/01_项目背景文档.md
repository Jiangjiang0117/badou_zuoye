# 项目背景文档
## 电商智能问答系统（意图识别技术与实战）

---

## 一、业务背景

随着电商平台规模的快速扩张，商品种类繁多、用户问题多样，传统客服模式面临以下挑战：

| 痛点 | 描述 |
|---|---|
| 信息量庞大 | 商品参数、运营活动、退换货政策等数据量级庞大，人工难以实时掌握 |
| 响应效率低 | 高峰期人工客服无法及时响应，用户等待时间长 |
| 回答质量参差不齐 | 不同客服人员对政策理解不一，答案不统一 |
| 成本高昂 | 大规模人工客服团队运营成本持续攀升 |

---

## 二、项目目标

构建一套基于**知识图谱 + 大语言模型**的电商智能问答系统，实现：

1. **精准意图识别**：理解用户自然语言表达的真实意图（查询商品、投诉售后、询问活动等）
2. **知识高效检索**：基于结构化知识图谱与向量检索，快速定位答案
3. **智能回答生成**：结合 RAG 技术与 Deepseek 大模型，生成准确、自然的回复
4. **提升用户体验**：将问答准确率提升至 93% 以上，显著降低用户流失

---

## 三、技术选型背景

### 3.1 为什么需要意图识别？

电商场景中用户表达多样，同一诉求可能有数十种表达方式，例如：
- "我的包裹怎么还没到？"
- "快递啥时候发？"
- "物流信息查询"

以上均属于**物流查询意图**，传统关键词匹配无法覆盖，需要 NLU（自然语言理解）模型进行语义理解。

### 3.2 为什么引入知识图谱？

- 电商知识具有**强关联性**（商品 → 品牌 → 售后政策 → 门店）
- 图数据库（Neo4j）天然支持关系查询，查询效率远高于关系型数据库
- 构建包含 **31,680 个实体**、多维关系的知识图谱，覆盖主要商品及服务场景

### 3.3 为什么采用 RAG 架构？

- 大模型存在知识截止日期，无法获取实时商品/活动信息
- RAG（检索增强生成）将**实时检索**与**语言生成**结合，确保答案时效性与准确性
- 避免大模型"幻觉"问题，提升回答可信度

---

## 四、项目价值

- **降本增效**：减少人工客服介入，节省人力成本 30%~50%
- **提升满意度**：7×24 小时实时响应，答案准确率 93%（测试集 1000 条）
- **可扩展性强**：知识图谱持续更新，系统随业务增长自动优化
- **技术复用**：意图识别模块可复用于推荐系统、搜索优化等场景

---

## 五、技术栈总览

| 技术模块 | 技术选型 | 用途 |
|---|---|---|
| 意图识别 | BiLSTM + CRF / R-BERT | 用户意图分类与实体抽取 |
| 知识图谱 | Neo4j | 存储电商知识三元组 |
| 关键词检索 | BM25 | 稀疏检索，补充向量检索 |
| 语义检索 | 向量数据库 | 密集检索，捕捉语义相似度 |
| 答案生成 | Deepseek 大模型 + RAG | 生成自然语言回复 |
| 实体识别 | R-BERT / BiLSTM+CRF | NER，F1-score 达 91.26% |
| 知识表示 | TF-IDF / 三元组嵌入 | 知识图谱向量化 |
