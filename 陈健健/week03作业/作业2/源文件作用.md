1.assets文件夹下管理项目静态资源 
2.doc文件夹下管理项目相关文档
3.logs文件夹下管理运行或错误日志
4.model文件夹下管理定义的工具函数
    a.bert.py定义的是根据bert实现意图识别分类的逻辑代码
    b.prompt.py定义的是通过llm实现意图识别分类的逻辑代码
    c.regex_rule.py定义的是通过正则校验的形式进行意图识别分类的逻辑代码
    d.tfidf_ml.py定义的是利用tfidf实现意图识别分类的逻辑代码
5.test文件夹下管理静态测试数据
6.config.py是统一管理变量数据，例如api等数据
7.data_schema.py是定义请求的请求参数和返回参数的数据结构和数据类型限制
8.fastapi_demp.py是一个 FastAPI 的 Demo 示例，搭建了一个简易的 HTTP Web 接口服务
9.logger.py是日志打印文件，控制台输出错误
10.main.py是项目的入口文件，定义接口内容
