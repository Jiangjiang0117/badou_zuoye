## 3. 功能详细设计

### F1 会话初始化与重置

**目标**：保证每次演示从干净状态开始，多轮上下文可追踪。

**触发**：
- 打开页面自动初始化；
- 用户点击“重置会话”。

**行为**：
1. 前端生成或从后端获取 `session_id`，存入 `st.session_state`。
2. 后端为该 `session_id` 初始化会话状态：对话历史、上一轮口径、上一轮结果列、纠错计数。
3. 重置时清空前端消息区与后端会话状态，生成新 `session_id`。

**状态字段**：
| 字段                | 说明                                     |
| ------------------- | ---------------------------------------- |
| session_id          | 会话唯一标识                             |
| history             | 对话历史（用户问题、口径卡片、结果摘要） |
| last_metric_spec    | 上一轮确认口径                           |
| last_result_columns | 上一轮结果列名                           |
| last_result_summary | 上一轮结果摘要（供指代使用）             |

**异常**：
- 后端会话不存在：自动重建，提示“会话已重置”。
- 重置失败：提示重试，不阻断页面。

**验收映射**：多轮验收组开始前需重置。

---

### F2 自然语言提问

**目标**：用户用自然语言输入业务问题。

**交互**：
- 聊天输入框，支持多行文本，Enter 提交（可配置 Shift+Enter 换行）。
- 提交后用户消息上屏，进入“解析中”状态。

**规则**：
- 空输入不提交。
- 单条问题建议 ≤200 字；超长提示“问题较长，建议简化”。
- 提交后禁用输入直到解析返回或超时。

**异常**：
- 解析超时：提示“解析超时，请重试或简化问题”。
- 解析服务不可用：提示“服务暂不可用”。

**验收映射**：20 题验收的输入入口。

---

### F3 口径解析与口径卡片

**目标**：把自然语言转成结构化口径，让用户确认系统理解是否正确。

**口径卡片字段**：
| 字段           | 是否必填 | 说明                     | 示例                                     |
| -------------- | -------- | ------------------------ | ---------------------------------------- |
| 问题复述       | 是       | 一句话复述               | “你想查 2024 年华东地区销售额，按月统计” |
| 指标           | 是       | 一个或多个指标           | 销售额                                   |
| 维度           | 否       | 分组维度                 | 月份                                     |
| 过滤条件       | 否       | 时间、地区、状态、品类等 | 地区=华东；年份=2024                     |
| 排序           | 否       | 排序字段与方向           | 按销售额降序                             |
| 限制           | 否       | TopN / LIMIT             | Top10                                    |
| 歧义提示       | 否       | 需用户确认的歧义         | “销售额指支付金额，不含退款，是否确认？” |
| 置信度（可选） | 否       | 低置信度高亮             | 低                                       |

**解析规则**：
- 指标必须映射到预定义指标口径（销售额、订单量、客单价、销量、退款率、退款额）。
- 维度必须来自白名单维度（月份、季度、年份、地区、品类、商品、客户等级等）。
- 未识别指标：口径卡片标记“未识别指标”，阻止确认执行，提示用户修改。
- 歧义：展示歧义提示，用户需在编辑中明确后才可确认。
- 多轮时：继承上一轮口径并合并，复述中体现完整口径。

**交互**：
- 卡片默认展开，字段以可编辑控件展示。
- 底部按钮：“重新解析”（自然语言重述）、“确认执行”（歧义未解决时禁用）。
- 低置信度字段高亮。

**异常**：
- 解析失败：展示原始问题与错误提示，提供“重试解析”。
- 返回非法枚举：标记字段错误，要求用户选择合法值。

**验收映射**：20 题每题均需生成合理口径；多轮需体现继承。

---

### F4 口径编辑与重新解析

**目标**：用户可纠正系统理解，确保“先确认再执行”。

**结构化编辑**：
- 指标：多选，来自预定义指标列表。
- 维度：多选，来自白名单维度。
- 过滤条件：键值对编辑，支持时间范围、地区、状态、品类。
- 排序：字段 + 升/降序。
- 限制：数字输入，默认无，最大 1000。
- 修改后卡片内“确认执行”可用（无未解决歧义时）。

**自然语言重述**：
- 输入框输入新描述，如“改成按品类统计，只看华南”。
- 点击“重新解析”，后端合并上一轮口径与新描述，返回新口径卡片。
- 重述不直接执行。

**规则**：
- 任何编辑都需用户再次点击“确认执行”才执行 SQL。
- 编辑不改变会话历史中的上一轮已确认口径，直到再次确认。
- 清空必填指标时禁用确认。

**异常**：
- 重述解析失败：保留原口径卡片，提示“重述未识别，请调整或手动编辑”。
- 编辑出非法组合（如维度不在白名单）：字段标红，禁用确认。

**验收映射**：验收时至少 3 题通过编辑纠正口径后成功。

---

### F5 确认执行

**目标**：口径确认后才生成并执行 SQL，保证可控。

**流程**：
1. 用户点击“确认执行”。
2. 前端提交 `session_id` + 最终口径。
3. 后端生成 SQL → 安全校验 → 执行。
4. 成功返回 SQL、结果、图表配置、文字总结；失败进入 F11。

**规则**：
- 未确认口径不执行 SQL。
- 确认后不再二次确认 SQL，直接执行，SQL 仅展示。
- 执行中展示 loading，禁用重复点击。
- 单次执行超时 10 秒。

**异常**：
- 安全校验不通过：提示“查询被安全策略拦截”，展示原因类别。
- 执行超时：提示“查询超时，请缩小范围”。
- 后端异常：提示“执行失败，请重试”。

**验收映射**：所有 20 题与多轮均经过此入口。

---

### F6 SQL 展示

**目标**：懂 SQL 的用户可查看生成 SQL。

**交互**：
- 结果区以折叠代码块展示 SQL，默认折叠。
- 提供“复制 SQL”按钮（可选）。
- 纠错时展示最终成功 SQL；失败时展示最后一次 SQL 与错误类别。

**规则**：
- SQL 只读，不允许在页面编辑执行。
- 展示的 SQL 为实际执行 SQL（含自动追加的 LIMIT）。

**异常**：无。

**验收映射**：每题检查 SQL 与口径一致。

---

### F7 结果表格

**目标**：展示查询结果。

**交互**：
- 表格展示，列名友好化（可保留原始列名）。
- 默认最多展示 1000 行，超出提示“已截断”。
- 支持列排序（Streamlit 原生能力）。

**规则**：
- 空结果：展示“未查询到数据”，并提示可调整口径。
- 结果列与口径维度/指标对应。

**异常**：
- 结果过大：截断并提示。
- 列类型异常：按字符串展示，不阻断。

**验收映射**：每题检查结果合理性。

---

### F8 自动图表

**目标**：自动选择合适图表，辅助理解。

**选图规则**：
| 条件                   | 图表                                     |
| ---------------------- | ---------------------------------------- |
| 时间维度 + 单指标      | `st.line_chart` 折线                     |
| 分类维度 + 单指标      | `st.bar_chart` 柱状                      |
| 多指标 + 时间/分类维度 | 柱状或折线，优先单指标；多指标可分开展示 |
| 无维度或明细结果       | 不出图，表格优先                         |
| 空结果                 | 不出图                                   |

**交互**：
- 图表展示在表格上方或下方（建议表格上方，先图后表）。
- 不做手动切换图表类型。
- 不做饼图、ECharts。

**异常**：
- 数据不适合绘图（如全空、单点）：不出图并说明“当前结果不适合绘图”。

**验收映射**：至少 10 题应出图且类型合理。

---

### F9 文字总结

**目标**：用自然语言解释结果，不编造数据。

**生成规则**：
- 基于结果数据、口径、SQL 生成。
- 必须包含：筛选条件、统计维度、结果行数。
- 建议包含：最高/最低值、趋势、排名要点。
- 不编造结果中不存在的数据。
- 长度 2～5 句。

**示例**：
> “2024 年华东地区销售额按月统计，共 12 个月；最高为 12 月，最低为 2 月，整体呈上升趋势。”

**异常**：
- 结果为空：总结说明未查询到数据及可能原因。
- 生成失败：回退为模板化总结（条件 + 行数）。

**验收映射**：每题检查总结与结果一致、无编造。

---

### F10 多轮上下文

**目标**：支持连续追问分析。

**支持类型**：
| 类型       | 示例                               | 规则                    |
| ---------- | ---------------------------------- | ----------------------- |
| 上下文继承 | “2024 年华东销售额” → “按月拆开”   | 继承指标/过滤，新增维度 |
| 指代省略   | 上一轮结果 → “那华南呢”            | 识别指代为地区切换      |
| 下钻/换维  | “按地区” → “按品类” / “下钻到商品” | 替换或新增维度          |

**规则**：
- 每轮解析都基于 `last_metric_spec` 合并新意图。
- 口径卡片展示合并后的**完整口径**，避免用户误解继承结果。
- 指代无法解析时，展示歧义提示，要求用户明确。
- 用户编辑口径后确认，更新 `last_metric_spec`。
- 重置会话清空上下文。

**异常**：
- 无上一轮上下文却说“那华南呢”：提示“请先提出一个查询”。
- 继承冲突（如指标矛盾）：展示歧义，要求用户选择。

**验收映射**：3 组多轮验收。

---

### F11 SQL 自动纠错

**目标**：SQL 失败时自动修正，提升成功率。

**触发**：SQL 执行失败（语法、字段、表名、类型、聚合错误等）。

**流程**：
1. 捕获错误，脱敏。
2. 将错误、schema、口径、上次 SQL 回喂 LLM。
3. LLM 返回修正 SQL。
4. 安全校验后再次执行。
5. 最多 2 次；成功则返回结果并标注“已自动纠错”；失败进入 F12。

**规则**：
- 纠错仅修正 SQL，不改变已确认口径。
- 纠错次数按单次确认执行计。
- 每次纠错展示在“执行过程”折叠区（可选）。

**异常**：
- 纠错返回非 SELECT：拦截并停止。
- 纠错后仍失败：展示最后一次错误类别。

**验收映射**：至少 1 题演示纠错成功；失败路径可演示。

---

### F12 错误提示与恢复

**目标**：失败时让用户知道下一步怎么做，不自动打断。

**错误分类与提示**：
| 类别       | 提示                                          | 恢复方式        |
| ---------- | --------------------------------------------- | --------------- |
| 解析失败   | “未理解问题，请调整描述或手动编辑口径”        | 重试解析 / 编辑 |
| 口径不完整 | “指标未识别，请选择指标”                      | 编辑口径        |
| 安全拦截   | “查询被安全策略拦截：仅支持只读查询”          | 修改口径        |
| 执行超时   | “查询超时，请缩小时间范围或减少维度”          | 修改口径        |
| 纠错失败   | “自动修正 2 次仍失败，可修改口径或问题后重试” | 用户决定        |
| 服务异常   | “服务暂不可用，请稍后重试”                    | 重试            |

**规则**：
- 纠错失败不自动回到口径编辑，只提示，由用户决定。
- 错误信息脱敏，不暴露连接串、密钥、系统表。

**验收映射**：失败路径演示。

---

### F13 演示脚本支持

**目标**：现场可顺序演示，减少临场风险。

**支持**：
- 前端提供“演示问题”快捷入口（可选）：点击填入输入框，不自动提交。
- 演示前重置会话。
- 保留一题失败纠错演示。

**脚本**：
- 10 个精选单轮 + 3 组多轮（见项目设计文档 9.3 / PRD 10）。

**验收映射**：演示彩排。

---

### F14（可选 P1）MCP 工具调用

**目标**：为后续扩展提供标准化工具层。

**范围**：
- `list_tables`、`describe_table`、`run_readonly_query`。
- 只读、白名单、LIMIT、超时与主链路一致。

**规则**：
- 不阻塞 Demo 核心链路；默认关闭，配置开启。
- 开启后替换本地工具函数，行为一致。

**验收映射**：不影响 P0 验收。

## 5. 状态与数据流转

```text
[初始] 
  → 输入问题 
  → [解析中] 
  → [待确认口径]（可编辑/重述）
  → 确认执行 
  → [执行中] 
      ├─ 成功 → [已出结果]
      └─ 失败 → [纠错中]（≤2次）
            ├─ 成功 → [已出结果]（标注已纠错）
            └─ 失败 → [错误提示]（用户决定）
  → 可继续提问（多轮）
  → 重置 → [初始]
```

**状态字段**：见 F1。前端需保存当前卡片口径草稿，避免刷新丢失（Demo 可接受丢失）。

## 6. 规则汇总

### 6.1 口径规则
- 指标、维度必须来自预定义白名单。
- 歧义未解决不可确认执行。
- 多轮继承后展示完整口径。
- 编辑后必须再次确认才执行。

### 6.2 SQL 规则
- 仅 SELECT、只读、白名单表、自动 LIMIT 1000、超时 10 秒。
- 口径确认后直接执行，不二次确认 SQL。
- 纠错 ≤2 次，仅修 SQL 不改口径。

### 6.3 展示规则
- 输出顺序：口径卡片 → 图表 → SQL → 表格 → 总结。
- 图表仅折线/柱状，自动选图，不手动切换。
- 总结不编造，失败回退模板。

### 6.4 错误规则
- 错误脱敏。
- 纠错失败只提示，不自动回口径编辑。
- 空结果提示可调整口径。
