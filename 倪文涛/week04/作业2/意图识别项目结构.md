# 项目结构说明

## 项目目录

```text
vibecodeing/
├── app/                          # 应用代码
│   ├── config/                   # 配置
│   │   └── settings.py           # 环境变量和资源路径
│   ├── dependencies/             # 依赖管理
│   │   └── model_factory.py      # 创建和缓存分类器
│   ├── models/                   # 分类器
│   │   ├── base.py               # 分类器基类和模型异常
│   │   ├── regex.py              # 正则分类器
│   │   ├── tfidf.py              # TF-IDF 分类器
│   │   ├── bert.py               # BERT 分类器
│   │   └── llm.py                # 大语言模型分类器
│   ├── routers/                  # 接口路由
│   │   └── intent_router.py      # 四种意图识别接口
│   ├── schemas/                  # 数据结构
│   │   └── intent.py             # 请求、响应和预测结果结构
│   ├── utils/                    # 工具函数
│   │   └── dataset.py            # 数据集读取工具
│   └── main.py                   # FastAPI 启动入口
├── assets/                       # 项目资源
│   ├── datasets/                 # 数据集
│   │   └── intent/
│   │       └── dataset.csv       # 意图分类数据集
│   ├── pretrained_models/        # 预训练模型
│   │   └── google-bert/
│   │       └── bert-base-chinese/ # 中文 BERT 基础模型
│   ├── rules/                    # 规则文件
│   │   └── regex_rules.yaml      # 正则分类规则
│   ├── stopwords/                # 停用词
│   │   └── baidu_stopwords.txt   # 百度中文停用词表
│   └── trained_models/           # 训练后的模型
│       ├── bert/                  # BERT 微调模型
│       └── tfidf/
│           └── model.joblib      # TF-IDF 模型文件
├── scripts/                      # 训练和评估脚本
│   ├── evaluate.py               # 模型评估脚本
│   ├── train_bert.py             # BERT 训练脚本
│   └── train_tfidf.py            # TF-IDF 训练脚本
├── tests/                        # 自动化测试
│   ├── test_api.py               # API 测试
│   ├── test_models.py            # 模型测试
│   └── test_regex_model.py       # 正则分类器测试
├── .env.example                  # 环境变量示例
├── .gitignore                    # Git 忽略配置
├── Makefile                      # 常用项目命令
├── pyproject.toml                # 项目依赖和工具配置
└── README.md                     # 项目使用说明
```

## 主要文件说明

| 文件 | 作用 |
|---|---|
| `app/main.py` | 创建 FastAPI 应用并注册路由和异常处理 |
| `app/routers/intent_router.py` | 提供 Regex、TF-IDF、BERT、LLM 四个接口 |
| `app/models/regex.py` | 使用正则规则识别意图 |
| `app/models/tfidf.py` | 使用 TF-IDF 模型识别意图 |
| `app/models/bert.py` | 使用微调后的 BERT 模型识别意图 |
| `app/models/llm.py` | 调用大语言模型识别意图 |
| `app/config/settings.py` | 管理环境变量和资源文件路径 |
| `app/dependencies/model_factory.py` | 创建并缓存分类器实例 |
| `app/schemas/intent.py` | 定义接口请求、响应和预测结果 |
| `assets/rules/regex_rules.yaml` | 保存正则表达式分类规则 |
| `assets/datasets/intent/dataset.csv` | 保存模型训练和评估数据 |
| `assets/trained_models/tfidf/model.joblib` | 保存训练后的 TF-IDF 模型 |
| `scripts/train_tfidf.py` | 训练并保存 TF-IDF 模型 |
| `scripts/train_bert.py` | 微调并保存 BERT 模型 |
| `scripts/evaluate.py` | 评估本地分类器效果 |
