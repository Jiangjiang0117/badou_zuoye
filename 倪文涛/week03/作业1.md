**langchain 工具调用 和 llm function call 有什么区别？**

1.  llm function call是大语言模型的原生工具调用能力，负责判断是否需要调用工具以及调用哪个工具并生成工具调用参数，不负责工具执行。开发者需要根据模型返回的工具信息完成工具调用，并将执行结果回传给模型，由模型生成最终回复；
2. langchain是基于大语言模型的开发框架，对llm function call等能力进行了封装和扩展，负责工具管理、工具执行、流程编排以及 Agent、Memory 等能力，简化了 AI 应用的开发流程；



**langchain 工具调用 的 速度是受到什么影响**

1. 大语言模型推理时间，判断是否调用工具、生成工具调用参数以及根据工具执行结果生成最终回复；
2. 工具执行时间，包括 MCP 工具、HTTP 接口、数据库查询等工具本身的执行耗时；
3. 工具调用数量：调用的工具越多，整体执行耗时越长；
4. langchain agent 模式，多轮大语言模型推理，多轮调用工具；
