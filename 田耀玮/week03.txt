作业1: 安装langchain 和 openai-agent，运行 langchain / 02_Model工具调用.py
    回答如下问题：
        1、 langchain 工具调用 和 llm function call 有什么区别？         
        答：LangChain 的「工具调用」底层本质就是 LLM 的 function call，只是在外面套了一层框架编排。 llm function call是模型原生能力，不同的大模型有不同的格式。 langchain 工具调用有统一的格式，由bind_tools()翻译成目标厂商格式。换模型可以几乎不改代码。
        2、 langchain 工具调用 的 速度是受到什么影响？
        答：1.和使用的大模型相关。 2.和任务复杂度相关。    3.和上下文长度相关。
