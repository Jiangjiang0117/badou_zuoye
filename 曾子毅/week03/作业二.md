# 作业二：意图识别项目代码梳理与流程图

## 一、源文件作用梳理

### 根目录（核心入口层）

| 文件 | 作用 |
|------|------|
| **main.py** | FastAPI 主应用入口，定义 4 个 POST 接口（regex / tfidf / bert / gpt），负责接收请求、调用模型、异常处理、计时和返回结果 |
| **config.py** | 全局配置文件，存放正则规则、类别名称列表、模型权重路径、大模型 API 地址/密钥等常量 |
| **data_schema.py** | 数据模型定义，用 Pydantic 定义 `TextClassifyRequest`（请求体）和 `TextClassifyResponse`（响应体）的数据结构与字段校验 |
| **logger.py** | 日志模块，配置日志同时输出到 `app.log` 文件和控制台，格式包含时间、模块名、级别和消息 |
| **fastapi_demp.py** | FastAPI 入门演示文件，提供简单的 GET 接口示例，非业务核心代码 |

### model/ 目录（模型推理层）

| 文件 | 作用 |
|------|------|
| **regex_rule.py** | 正则规则分类器。启动时预编译正则表达式，推理时通过关键词匹配判断文本所属类别，匹配不到则归为 `Other` |
| **tfidf_ml.py** | TF-IDF + 传统机器学习分类器。流程：jieba 分词 → 去停用词 → TF-IDF 向量化 → 加载预训练 ML 模型预测 → 返回分类结果 |
| **bert.py** | BERT 深度学习分类器。流程：加载预训练 BERT 模型和微调权重 → Tokenizer 编码文本 → 构建 DataLoader → 模型前向推理 → argmax 取最大概率类别 → 映射为类别名返回 |
| **prompt.py** | 大模型（LLM）分类器。采用 **TF-IDF 检索 + Few-shot Learning** 方案：用 TF-IDF 计算待分类文本与训练集的相似度，取 Top10 相似样本作为参考示例，构建动态 Prompt 调用大模型 API，返回分类结果 |

### 其他目录

| 目录 | 作用 |
|------|------|
| **assets/dataset/** | 训练数据集（dataset.csv）和百度停用词表 |
| **assets/weights/** | 预训练模型权重文件（tfidf_ml.pkl、bert.pt） |
| **training_code/** | 模型训练脚本（train_bert.py、train_tfidf.py），用于训练得到权重文件 |
| **test/** | 测试数据（data.json） |
| **doc/** | 项目文档（背景、实施、运维、面试点） |
| **logs/** | TensorBoard 训练日志 |

## 二、FastAPI 请求 → 返回结果 完整流程图

以 `/v1/text-cls/bert` 接口为例，4 个接口结构完全一致，仅调用的模型函数不同：

```
┌─────────────────────────────────────────────────────────────┐
│                     客户端（浏览器/Postman）                  │
│            POST /v1/text-cls/bert  {请求体 JSON}             │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTP 请求
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    FastAPI 应用 (main.py)                    │
│  ① 路由匹配：找到 @app.post("/v1/text-cls/bert") 处理函数      │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│               Pydantic 数据校验 (data_schema.py)             │
│  ② 自动将 JSON 请求体解析为 TextClassifyRequest 对象           │
│     校验字段类型：request_id(可选)、request_text(str/list)     │
│     校验失败 → 自动返回 422 错误（不进入业务逻辑）                │
└───────────────────────────┬─────────────────────────────────┘
                            │ 校验通过
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    接口处理函数 (bert_classify)               │
│  ③ 记录开始时间 start_time = time.time()                      │
│  ④ 初始化响应对象 TextClassifyResponse（全空默认值）            │
│  ⑤ 打印请求日志 logger.info（写入 app.log + 控制台）            │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                      try 异常捕获块                          │
│  ⑥ 调用模型函数 model_for_bert(request_text)                  │
└───────────────────────────┬─────────────────────────────────┘
                            │
              ┌─────────────┴─────────────┐
              │                           │
              ▼                           ▼
    ┌───────────────────┐       ┌───────────────────┐
    │   模型推理成功      │       │    抛出异常        │
    │ classify_result   │       │  捕获 Exception   │
    │  = 分类结果        │       │ error_msg =       │
    │ error_msg = "ok"  │       │  traceback堆栈信息 │
    └─────────┬─────────┘       └─────────┬─────────┘
              │                           │
              └─────────────┬─────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  ⑦ 计算耗时：classify_time = round(当前时间 - start_time, 3)   │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  ⑧ return TextClassifyResponse                              │
│     FastAPI 自动将 Pydantic 对象序列化为 JSON                 │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTP 响应
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                     客户端收到 JSON 响应                      │
│  {                                                          │
│    "request_id": "...",                                     │
│    "request_text": "...",                                   │
│    "classify_result": "Music-Play",                         │
│    "classify_time": 0.123,                                  │
│    "error_msg": "ok"                                        │
│  }                                                          │
└─────────────────────────────────────────────────────────────┘
```

## 三、四种模型内部推理路径对比

| 步骤 | 正则规则 (regex) | TF-IDF 机器学习 | BERT 深度学习 | 大模型 (GPT/LLM) |
|------|-----------------|----------------|--------------|-----------------|
| **输入处理** | 直接用原文 | jieba分词 + 去停用词 | Tokenizer 编码 | TF-IDF 向量化 |
| **核心算法** | 正则关键词匹配 | TF-IDF + 预训练分类器 | BERT 前向传播 | 相似度检索 + Few-shot + LLM |
| **输出方式** | 匹配到的类别名列表 | 模型预测的类别列表 | argmax → 类别名映射 | 大模型返回的文本 |
| **速度** | 极快（微秒级） | 快（毫秒级） | 较慢（百毫秒级） | 最慢（秒级，依赖网络） |
| **精度** | 低（只能匹配规则内的） | 中 | 高 | 最高（但有幻觉风险） |

> **关键设计点**：4 个接口共用同一套 `TextClassifyRequest` / `TextClassifyResponse` 数据结构，支持单条（str）和批量（list）两种输入模式，每个接口都做了完整的异常捕获和耗时统计，体现了工程化 API 服务的标准写法。
