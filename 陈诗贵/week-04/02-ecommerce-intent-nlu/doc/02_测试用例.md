# 电商智能问答系统 · NLU 意图识别模块 — 测试用例设计

> 版本：v1.0
> 关联：`01_产品文档.md`

---

## 1. 测试目标与范围

- **目标**：验证意图识别模块在功能正确性、边界健壮性、接口契约与性能上满足产品文档要求。
- **范围**：数据集、模型层（TF-IDF / BERT）、FastAPI 接口。
- **通过标准**：验证集 Accuracy ≥ 0.90，所有 P0/P1 用例通过，接口契约无偏差。

## 2. 测试环境

| 项 | 值 |
|----|----|
| OS | Windows / Linux |
| Python | 3.10+ |
| 关键依赖 | transformers, torch, sklearn, fastapi, pytest, jieba |
| 硬件 | CPU（可运行），GPU 可选 |

## 4. 边界与异常用例

| 用例ID | 场景 | 输入 | 期望行为 | 优先级 |
|--------|------|------|----------|--------|
| EDGE-01 | 空字符串 | `""` | 返回 `Other`（或明确错误，不崩溃） | P0 |
| EDGE-02 | 纯空白 | `"   "` | 返回 `Other`，不崩溃 | P1 |
| EDGE-03 | 超长文本 | 2000+ 字符 | 不超时、正常返回；BERT 按 max_length 截断 | P1 |
| EDGE-04 | 纯数字 | `"123456789"` | 返回 `Other`，不崩溃 | P1 |
| EDGE-05 | 纯英文 | `"where is my order"` | 返回某个类别或 `Other`，不崩溃 | P1 |
| EDGE-06 | 特殊符号 | `"!!!???@#￥"` | 返回 `Other`，不崩溃 | P1 |
| EDGE-07 | 中英混合 | `"iPhone 15 pro 多少钱"` | 返回 `Price-Query`（语义优先） | P2 |
| EDGE-08 | 单字 | `"退"` | 返回 `Return-Refund` 或 `Other`，不崩溃 | P1 |
| EDGE-09 | 多意图混合 | `"订单发货了，但我想退货"` | 返回主意图之一（不崩溃），标注倾向 `Return-Refund` | P2 |
| EDGE-10 | None / 缺字段 | 缺少 `request_text` | 返回 422 参数校验错误 | P0 |
| EDGE-11 | 错误类型 | `request_text` 传数字 | 返回 422 参数校验错误 | P1 |
| EDGE-12 | 批量输入 | `["多少钱","快递到哪了"]` | 按顺序返回 `["Price-Query","Logistics-Query"]` | P0 |
| EDGE-13 | 空批量 | `[]` | 返回空列表，不崩溃 | P1 |

## 5. 接口测试用例

| 用例ID | 路由 | 断言 | 优先级 |
