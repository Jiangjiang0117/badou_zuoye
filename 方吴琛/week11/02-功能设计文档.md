# 功能设计文档（Functional Design Document）

## 1. 功能概述

杭州租房 ChatBI 的核心功能：**用户以自然语言提问，系统自动生成 SQL 查询房源数据，并以表格与图表返回结果，支持多轮追问**。

## 2. 用户角色与使用场景

| 角色 | 描述 | 典型诉求 |
|---|---|---|
| 租客（主用户） | 在杭州找房、无 SQL 技能 | 按预算/户型/区位/近地铁筛选；对比各区租金 |
| 数据分析演示者 | 展示 ChatBI 能力 | 用示例问题快速演示查询与可视化 |

## 4. 核心功能详细设计

### 4.1 F1/F2/F3：NL→SQL 查询

**输入**：用户自然语言问句（可含多个条件）。
**处理**：
1. 语义层生成系统提示词（表结构 + 字段字典 + 指标库 + 规则）。
2. 结合历史上下文，大模型输出候选 SQL。
3. 规则校验（用错字段 / 整数除法 / 非只读）。
4. 执行 SQLite；失败则错误自纠，最多 2 次。
**输出**：列名 + 行数据。

**条件解析规则**：

| 用户说法 | 映射 |
|---|---|
| "两居 / 两室 / 2室" | rooms=2 |
| "近地铁 / 地铁旁" | near_metro=1 |
| "xx 以内 / 预算 xx" | rent <= xx |
| "精装 / 简装 / 毛坯" | decoration='精装' 等 |
| "朝南" | orientation='朝南' |
| "整租 / 合租" | rent_type='整租' 等 |
| "未来科技城 / 下沙" | 板块（block），注意非区 |

### 4.2 F6：多轮上下文

- 前端维护 `st.session_state.history`，最近 4 轮（用户问 + 助手摘要）作为上下文。
- 上下文仅传最近几轮，避免长对话 token 膨胀。
- 助手侧记录"结果行数 + 生成的 SQL"作为压缩摘要，供后续轮次参考。

### 4.3 F7：错误自纠

- 首次 SQL 执行抛 `sqlite3.Error` 时，把**原始问题 + 出错 SQL + 错误信息**回喂模型，要求修正后重新输出 SQL。
- 自纠最多 2 轮，仍失败则返回错误说明。
- 自纠前先做规则校验，识别明显逻辑错误（用错字段、整数除法算出 0% 占比）。

## 5. 交互流程

### 5.1 单轮查询流程

```
用户在输入框输入问题
   │
   ▼
追加用户消息到对话区
   │
   ▼
组装历史上下文(最近4轮)
   │
   ▼
NL→SQL Agent：
  ├─ 生成SQL（Pydantic约束 + 规则校验）
  ├─ 执行SQLite（失败则自纠≤2次）
  └─ 返回 列名+行
   │
   ▼
前端渲染：
  ├─ 回答文本（共N条结果 / 无匹配提示）
  ├─ 数据表格
  ├─ 若存在「文本列+数值列」→ 自动柱状图
  └─ 可展开查看 SQL
   │
   ▼
记录结果摘要到历史
```

### 5.2 侧边栏交互

- 显示当前模型后端信息（本地 Ollama / API）。
- 提供 7 个示例问题按钮，点击即自动填入提问。

## 6. 示例对话（验收用例）

| # | 用户问题 | 预期 SQL 要点 | 预期结果 |
|---|---|---|---|
| 1 | 杭州各区平均租金是多少？ | GROUP BY district, AVG(rent) | 9 行各区平均租金 + 柱状图 |
| 2 | 哪个区平均租金最高？ | AVG(rent) ORDER BY DESC LIMIT 1 | 上城区 |
| 3 | 各区近地铁房源占比？ | SUM(near_metro)*100.0/COUNT(*) | 各占比（43%~48%） |
| 4 | 拱墅区3000以内两居室 | district='拱墅区' AND rent<=3000 AND rooms=2 | 匹配房源或空 |
| 5 | 未来科技城近地铁平均租金 | block='未来科技城' AND near_metro=1 | 一个均值 |
| 6 | 西湖区朝南整租一居室 | district='西湖区' AND orientation='朝南' AND rooms=1 AND rent_type='整租' | 匹配房源 |
| 7 | 杭州三居室5000以内精装 | rooms=3 AND rent<=5000 AND decoration='精装' | 匹配房源 |

## 7. 功能边界与限制

| 限制 | 说明 |
|---|---|
| 数据范围 | 仅覆盖仿真数据集内的字段与取值；范围外问题返回空并如实说明 |
| 模型能力 | 本地 qwen3:0.6b 对复杂语义理解不稳定，建议升级更强模型 |
| 非数值分析 | 不支持预测、趋势外推、地图联动 |
| 只读 | 仅支持 SELECT 查询，禁止写操作 |
