## 2. M1 用户管理

### 2.1 功能点

| ID | 功能 | 输入 | 输出 | 规则 |
|---|---|---|---|---|
| U1 | 注册 | 用户名、密码、角色 | 用户记录 | 用户名唯一，密码加盐哈希，新用户默认启用 |
| U2 | 登录 | 用户名、密码 | 会话态 | 失败 5 次锁定 10 分钟 |
| U3 | 改密 | 用户名、旧密码、新密码 | 结果 | 校验旧密码，长度不少于 8 位 |
| U4 | 用户列表 | 分页参数 | 列表 | 仅管理员 |
| U5 | 启停 | 用户名、状态 | 结果 | 停用后令牌立即失效 |
| U6 | 删除 | 用户名 | 结果 | 软删除，保留审计 |

### 2.2 主流程

```
输入 → 查用户表 → 密码校验 → 生成令牌 → 返回用户名与角色
                              ↘ 失败：错误码加剩余尝试次数
```

### 2.3 异常分支

| 分支 | 处理 |
|---|---|
| 用户不存在 | 统一返回用户名或密码错误，不暴露账号是否存在 |
| 账号停用 | 返回 403，提示联系管理员 |
| 密码错误 5 次 | 锁定并在响应中带 `retry_after` 字段 |

## 3. M2 对话模块

### 3.1 会话管理

| ID | 功能 | 说明 |
|---|---|---|
| C0 | 新建会话 | 前端调 `/v1/chat/init` 取 12 位随机会话标识 |
| C1 | 会话列表 | 按用户列出标题，取首问截断 100 字，附开始时间 |
| C2 | 切换会话 | 按会话标识拉取全部消息，跳过系统角色消息 |
| C3 | 删除会话 | 级联删除消息 |
| C4 | 清空当前聊天 | 前端重置会话缓存，后端保留历史 |
| C5 | 反馈 | 对单条助手消息赞或踩，记录时间 |

### 3.2 提问流程

```
用户输入，文本加可选附件
  → 无会话标识则先初始化
  → 后端落库用户消息
  → 按任务类型渲染系统提示词，股票分析、数据 BI、闲聊三套
  → 分支：
     A. 未勾选工具 → 纯模型流式回答
     B. 勾选工具 → 连 MCP 服务，按工具白名单过滤
        · 命中可视化工具 history_k_data → 首个工具结果即答案
        · 其余 → 工具结果再喂模型总结
  → SSE 逐块推送
  → 落库助手消息
```

### 3.3 流式输出协议

| 片段类型 | 格式 | 前端处理 |
|---|---|---|
| 正文 | 纯文本增量 | 追加渲染，尾部加光标表示生成中 |
| 工具调用 | 代码块内书写工具名与参数 | 解析参数，命中可视图表工具则回填图表 |

工具调用块以工具名开头。一次回答可能有多个工具调用，前端不能只取第一个代码块，必须按工具名匹配参数。

### 3.4 工具勾选交互

| 交互 | 规则 |
|---|---|
| 工具列表加载 | 前端连 MCP 拉取工具列表，缓存 60 秒 |
| 默认状态 | 全不选，进入纯对话模式，避免误调用产生费用 |
| 多选 | 支持，等价于工具白名单 |
| 服务不可用 | 侧边栏报错，降级为纯对话，不阻塞提问 |
| 全选 | 提供一键全选 |

### 3.5 歧义澄清

命中以下信号时先问再查，不猜：

| 信号 | 示例 | 澄清话术 |
|---|---|---|
| 指标多口径 | 销售额 | 含税还是不含税，退款的订单要扣掉吗 |
| 时间模糊 | 最近 | 默认近 30 天，从 10 月 1 日到 10 月 31 日，可以吗 |
| 粒度不明 | 手机销量 | 按天还是按月，按单品还是按品类 |
| 实体歧义 | 苹果 | 指 Apple 公司，还是苹果品类 |

实现方式：生成 SQL 前增加一次轻量判定，可交给小模型完成，返回需要澄清时直接输出问题，不执行查询。

### 3.6 结果呈现规范

每次回答必须包含三部分：结论、可视化、可验证信息。结论是一句话带数字和单位，可验证信息放在折叠区，含 SQL、数据表、时间范围、数据更新时间。

| 数据形状 | 图表 |
|---|---|
| 时间序列 | 折线图 |
| 分类对比，不超过 15 类 | 柱状图 |
| 占比 | 饼图或堆叠柱 |
| 明细，超过 15 行 | 表格加导出 |
| 单值指标 | 大数字加同比环比 |

## 4. M3 数据管理

| ID | 功能 | 说明 |
|---|---|---|
| D1 | 数据源接入 | 填连接串，测试连通，标记敏感字段 |
| D2 | 元数据同步 | 拉取结构加数据画像，写入元数据表，显示最近同步时间 |
| D3 | 字段语义维护 | 中文名、单位、枚举解释、是否敏感 |
| D4 | 指标字典 | 指标名、公式、口径、粒度、责任人、同义词 |
| D5 | 上传文件 | 支持 CSV 与 Excel，解析表头，推断类型，生成临时表后可问答 |
| D6 | 数据预览 | 前 100 行加字段画像摘要 |

### 4.1 指标字典结构

| 字段 | 说明 | 示例 |
|---|---|---|
| metric_name | 指标名 | 销售额 |
| synonyms | 同义词 | 营收、收入、成交额 |
| formula | 计算表达式 | `SUM(order_amount)` |
| caliber | 口径说明 | 不含税，剔除退款，按支付时间 |
| grain | 默认粒度 | 按天 |
| owner | 责任人 | 数据组张三 |
| status | 状态 | 已确认或待确认 |

把口径从提示词里搬到数据库里。提示词里的口径会随模型漂移，表里的不会。

## 5. M4 股票看板

| ID | 功能 | 数据源 | 说明 |
|---|---|---|---|
| S1 | 股票搜索 | baostock | 代码与名称模糊搜索 |
| S2 | 基本信息 | baostock | 名称、行业、上市日期、估值 |
| S3 | K 线 | `history_k_data` | 周期支持日、周、月、5 分钟、15 分钟、30 分钟、60 分钟，前端用蜡烛图加成交量 |
| S4 | 排行 | baostock | 按涨跌幅、换手率、成交额取前 N |
| S5 | 板块与行业 | baostock | 板块成分与涨跌 |
| S6 | 自选 | 本地库 | 添加、删除、清空，按用户隔离 |

### 5.1 K 线回填流程

```
用户问：看下 600519 最近三个月的走势
  → 智能体选择 history_k_data
  → 流式输出工具名与参数，含代码、周期、起止日期
  → 前端按工具名提取参数
  → 调后端 K 线接口拿原始行
  → 转数据框并做数值化，绘制蜡烛图与成交量
```

模型输出不了像素，只能输出参数。图由前端用真实数据绘制，模型只负责决定查什么。

## 6. M5 工具中心

| ID | 功能 | 说明 |
|---|---|---|
| T1 | 工具发现 | 连 MCP 拉取工具列表，展示名称、描述、入参结构 |
| T2 | 工具调试 | 按入参结构动态生成表单，直接调用查看原始返回 |
| T3 | 工具启用 | 默认关闭，审核后启用，防止模型调用未验证工具 |
| T4 | 工具授权 | 按用户或角色配置白名单 |
| T5 | 外部接口导入 | 从接口描述文件生成工具，默认只允许 GET |
| T6 | 写入确认 | 写操作生成待确认操作，用户确认后才执行 |

工具分级：

| 级别 | 类型 | 策略 |
|---|---|---|
| L1 | 只读查询 | 可直接调用 |
| L2 | 只读但高成本，如大表或外部付费接口 | 需配额加超时 |
| L3 | 写入 | 必须二次确认加审计 |
| L4 | 危险操作，如删除、转账 | 不进工具池 |

## 7. M6 评测看板

| ID | 功能 | 说明 |
|---|---|---|
| E1 | 标准答案集管理 | 四元组：问题、SQL、结果、自然语言答案，支持导入导出 |
| E2 | 回归执行 | 一键跑全量，输出通过率与错误分类 |
| E3 | 错误归因 | 按表选择错、字段错、聚合错、时间窗错、关联错归类 |
| E4 | 差评回流 | 用户点踩后进候选集，人工确认后入标准答案集 |
| E5 | 报告类评测 | 无标准答案时按维度打分：完整性、逻辑性、深度、排版 |

指标定义：

| 指标 | 计算 |
|---|---|
| 执行成功率 | 执行无异常的条数除以总数 |
| 业务正确率 | 与标准结果一致且数值容差 ±0.5% 的条数除以总数 |
| 改写轮次分布 | 0 至 3 轮各占比，超过 3 轮视为失败 |
| 平均延迟 | 首次问句到最后一个 token 的耗时 |

## 8. 接口清单

### 8.1 业务接口

| 方法 | 路径 | 入参 | 出参 | 说明 |
|---|---|---|---|---|
| POST | `/v1/chat/init` | 无 | 会话标识 | 新建会话 |
| POST | `/v1/chat/` | 内容、用户名、会话标识、任务、工具列表 | 事件流 | 流式问答 |
| POST | `/v1/chat/get` | 会话标识 | 消息列表 | 历史消息 |
| POST | `/v1/chat/list` | 用户名 | 会话列表 | 侧边栏 |
| POST | `/v1/chat/delete` | 会话标识 | 无 | 删除会话 |
| POST | `/v1/chat/feedback` | 会话标识、消息 ID、反馈值 | 无 | 赞或踩 |
| POST | `/v1/stock/list_fav_stock` | 用户名 | 自选列表 | 自选股 |
| POST | `/v1/stock/add_fav_stock` | 用户名、股票代码 | 无 | 加自选 |
| POST | `/v1/stock/del_fav_stock` | 用户名、股票代码 | 无 | 删自选 |
| POST | `/v1/stock/clear_fav_stock` | 用户名 | 无 | 清空自选 |
| POST | `/v1/user/login` | 用户名、密码 | 令牌 | 登录 |
| POST | `/v1/user/register` | 用户名、密码、角色 | 无 | 注册 |
| POST | `/v1/user/reset` | 用户名、旧密码、新密码 | 无 | 改密 |
| POST | `/v1/user/list` | 无 | 用户列表 | 管理员 |

### 8.2 底层接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/stock/api/kline/history` | K 线原始数据，直接透传数据源结果 |
| POST | `/stock/api/stock/basic` | 基本信息 |
| POST | `/stock/api/stock/search` | 搜索 |

挂载策略：底层接口用 `app.mount` 挂到 `/stock`，同时用 `FastMCP.from_fastapi` 复用同一份接口定义。一份代码两种消费方式，HTTP 给前端，MCP 给智能体。

### 8.3 统一响应包

```json
{ "code": 200, "message": "ok", "data": {} }
```

状态码约定：200 成功，4xx 参数或权限错误，500 服务异常。异常时服务端记录完整堆栈，响应只返回异常类型和一句话，不向前端泄露 SQL、库名与表结构。

## 9. 权限矩阵

| 功能 | 普通用户 | 分析师 | 管理员 |
|---|---|---|---|
| 对话，无工具 | 可用 | 可用 | 可用 |
| 对话，只读工具 | 按授权 | 可用 | 可用 |
| 对话，写入工具 | 需确认 | 需确认 | 需确认加审计 |
| 看全量数据 | 不可，行级过滤 | 可用 | 可用 |
| 指标字典维护 | 不可 | 提建议 | 可用 |
| 数据源接入 | 不可 | 不可 | 可用 |
| 用户管理 | 不可 | 不可 | 可用 |
| 评测集维护 | 不可 | 可用 | 可用 |

行级权限实现：SQL 生成后、执行前注入过滤条件，按用户可见范围限定，不靠提示词约束模型。

## 10. 异常与降级

| 场景 | 表现 | 处理 |
|---|---|---|
| MCP 服务未启动 | 工具列表为空 | 降级纯对话，侧边栏提示，不阻塞主流程 |
| 模型超时 20 秒 | 流中断 | 保留已输出内容，标注回答未完成可重试 |
| SQL 连续 3 次失败 | 无法回答 | 返回错误分类加建议，如该指标未定义请联系数据组 |
| 结果为空集 | 空表 | 区分真无数据与条件过严，后者建议放宽条件 |
| 查询超过 30 秒 | 超时 | 建议加时间范围或缩小维度，提示改用汇总表 |
| 命中敏感字段 | 请求被拒 | 提示字段不可查询，记录审计 |
| 上下文过长 | 历史被截断 | 只保留最近 10 轮，过长会让模型忘记最初信息 |

## 11. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 首字 P95 不超过 2 秒，完整回答 P95 不超过 15 秒，单次工具调用不超过 20 秒 |
| 并发 | 内部 100 人使用，同步阻塞式足够；对外服务需异步化 |
| 可用性 | 单机部署可接受，MCP 与后端解耦，可独立重启 |
| 安全 | 只读账号、SQL 白名单、敏感字段拦截、全量审计日志 |
| 合规 | 数据分级决定模型部署方式，L2 以上不出内网 |
| 可维护 | 换模型只改环境变量，加工具只加装饰器，不改智能体代码 |
| 可观测 | 每条问答有过程轨迹：表选择、SQL、改写次数、耗时、token 数 |
