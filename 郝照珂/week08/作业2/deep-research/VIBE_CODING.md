# Vibe Coding 实施记录

## 需求输入

用户要求完成第八周：配置 Claude Code，使用 Skill、Hook、MCP 并分别截图；自行实现课程综合案例 02。
从课程压缩包读取规格后确认案例是“深度研究助手”，再将要求整理为 REQUIREMENTS.md。

## 自然语言开发步骤

1. 按课程规格实现研究循环：规划子问题、搜索摘要、提取结论、判断补检、综合报告。要求全部记录可保存，引用可追溯。
2. 加入不用密钥的明确演示模式，同时保留真实 API 接入；避免把演示数据伪装成实时研究。
3. 制作中文工作台，包含主题输入、模式、轮数、历史记录、报告、来源和研究过程标签页。
4. 写有意义的边界测试，覆盖轮数上限、错误引用、无来源、配置缺失和重启恢复。
5. 用 Claude Code 的 research-check Skill 做只读代码验收，并调用 MCP 工具验证作业要求，自动触发 Hook 保存事件。
6. 通过浏览器真实点击完成任务，核对两次补检判断、两条来源、下载、刷新后的历史、手机宽度和输入错误响应。

## 反馈与修正

- Claude Code 首次在沙箱内连接失败，获得网络执行权限后使用既有模型服务验证成功。
- Playwright 默认浏览器未安装，改用本机 Edge 完成截图与交互验收。
- 演示中微调子问题最初重复展示 RAG 摘要，改为明确呈现“当前资料不足、需补检”，使过程与主题匹配。
- 补充非法引用整条降级策略，避免仅剔除坏编号后让整条结论看似得到支持。

## 事实边界

开发与测试由本次 AI 辅助完成；Claude Code 单独完成了有日志的只读验收与工具调用。没有声称所有源代码都由 Claude Code 生成，也没有声称未运行的真实联网研究已经通过。
