# 综合案例 02 · 深度研究助手

规格来源：week08/Week08/Part2-VibeCoding实操.zip 中 综合案例-02/README.md。
该实现重新编写后端与前端，不复制课件中的密钥或原有运行记录。

1. 输入主题，规划子问题，多轮搜索，提取资料，判断是否补检，最后综合。
2. 输出摘要、分节正文、关键结论、遗留问题。
3. 来源有标题、URL、站点、访问时间；结论关联来源编号。
4. 保存关键词、阅读摘要的页面 URL、迭代轮数、每一步时间与判断。
5. 给出置信度说明和信息截止时间；无来源内容标注模型推断。
6. 提供任务历史、进度、错误状态、Markdown / JSON 下载和适配手机的界面。
7. 离线演示仅支持预设“RAG 与微调如何选择”，使用固定教学样例，不能作为真实研究结论。
8. 实时模式使用 Bocha 搜索摘要和 OpenAI 兼容 Chat Completions API；不是完整网页爬取。
9. 任务 JSON 原子写入；重启后将未完成任务标为 interrupted。

验收：离线端到端完成至少两轮；空主题拒绝；缺失配置明确失败；非法来源引用降为模型推断；可回看历史与下载报告。
