  请求 → 响应 完整流程

  客户端                          FastAPI 框架                       模型推理层
  ─────                          ────────────                      ─────────

  HTTP POST
  /v1/text-cls/{model}
    │
    ▼
  路由匹配 ──► 找到对应端点函数
    │
    ▼
  Pydantic 校验 ──► TextClassifyRequest 自动验证
    │                     │
    │                     ├─ 失败 → 422 Unprocessable Entity
    │                     │
    │                     └─ 通过 → 进入端点处理函数
    │                                    │
    │                              start_time = time.time()
    │                                    │
    │                              TextClassifyResponse(初始化)
    │                                    │
    │                              logger.info(记录请求)
    │                                    │
    │                         ┌──────────┴──────────┐
    │                         │   调用模型函数        │
    │                         ▼                      ▼
    │                  model_for_xxx()          try/except
    │                         │                成功: error_msg="ok"
    │                         │                失败: error_msg=traceback
    │                         │                      │
    │                         └──────────┬───────────┘
    │                                    │
    │                         classify_time = 耗时
    │                                    │
    │                         return TextClassifyResponse
    │                                    │
    ▼                                    ▼
  JSON 响应 ◄──── FastAPI 自动序列化 Pydantic → JSON
  (200 OK)
